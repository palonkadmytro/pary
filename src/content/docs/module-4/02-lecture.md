## Мета заняття

- Навчитися оголошувати змінні та константи, знати правила іменування.
- Розібратися в системі типів PHP: скалярні, складені та спеціальні типи; динамічна типізація та приведення (type juggling).
- Зрозуміти різницю між нестрогим `==` і строгим `===` порівнянням та зміни в PHP 8.

- Ознайомитися з індексованими, асоціативними та багатовимірними масивами.

## 1. Змінні і константи

### Змінні

Змінна в PHP завжди починається зі знака **`$`**, за яким іде ім'я:

```php
<?php
$name = 'Олена';
$age = 19;
$isStudent = true;
$averageGrade = 4.7;
```

Правила іменування:

- ім'я починається з літери або `_`, далі — літери, цифри, `_`;
- імена змінних **чутливі до регістру**: `$name` і `$Name` — різні змінні;
- оголошувати змінну заздалегідь чи вказувати тип не потрібно — вона створюється при першому присвоєнні;
- за домовленістю — `$camelCase` або `$snake_case`, англійською мовою і змістовно (`$totalPrice`, а не `$tp`).

:::note
На відміну від імен змінних, імена **функцій і ключові слова** в PHP регістр **не** враховують: `ECHO`, `Echo` і `echo` працюють однаково. Але пишіть завжди малими літерами.
:::

Звернення до змінної, якій ще нічого не присвоєно, дає попередження `Warning: Undefined variable $x` і значення `null`. Перевірити існування змінної можна за допомогою `isset($x)` (повертає `false`, якщо змінної немає **або** вона дорівнює `null`).

### Присвоєння за значенням і за посиланням

За замовчуванням присвоєння **копіює значення**:

```php
$a = 10;
$b = $a;   // копія
$b = 20;
echo $a;   // 10 — $a не змінилася

$c = &$a;  // посилання: $c — інше ім'я для тієї самої змінної
$c = 30;
echo $a;   // 30
```

Масиви в PHP теж копіюються при присвоєнні (на відміну від JavaScript, де масиви й об'єкти передаються за посиланням). Насправді PHP використовує оптимізацію *copy-on-write*: справжня копія створюється лише тоді, коли одну з змінних змінюють.

```php
$list = [1, 2, 3];
$copy = $list;
$copy[] = 4;
echo count($list); // 3 — оригінал не змінився (в JS було б 4!)
```

### Константи

Константа — іменоване значення, яке не можна змінити після оголошення. Імена констант пишуть ВЕЛИКИМИ ЛІТЕРАМИ і **без** `$`:

```php
const SITE_NAME = 'Міні-блог';           // оголошення на етапі компіляції (рекомендовано)
const MAX_TITLE_LENGTH = 120;
define('UPLOAD_DIR', __DIR__ . '/uploads'); // функція: виконується під час роботи скрипту

echo SITE_NAME;
```

| | `const` | `define()` |
|---|---|---|
| Коли визначається | під час компіляції | під час виконання |
| Можна всередині `if` | ні | так |
| Можна в класі | так | ні |
| Значення | константний вираз | будь-який вираз |

### Вбудовані та «магічні» константи

| Константа | Значення |
|---|---|
| `PHP_VERSION` | версія PHP, наприклад `"8.4.3"` |
| `PHP_EOL` | символ кінця рядка для поточної ОС |
| `PHP_INT_MAX` | найбільше ціле число (`9223372036854775807` на 64-бітних системах) |
| `__DIR__` | абсолютний шлях до папки поточного файлу |
| `__FILE__` | абсолютний шлях до поточного файлу |
| `__LINE__` | номер поточного рядка |

`__DIR__` знадобиться нам постійно: `require __DIR__ . '/includes/helpers.php'` надійно підключає файл незалежно від того, звідки запущено скрипт.

## 2. Типи даних

PHP — **динамічно типізована** мова: тип належить значенню, а не змінній. Одна змінна може послідовно містити рядок, число і масив.

| Категорія | Тип | Приклад |
|---|---|---|
| Скалярні | `bool` | `true`, `false` |
| | `int` | `42`, `-7`, `0x1A` (шістнадцяткове), `0b101` (двійкове), `1_000_000` |
| | `float` | `3.14`, `1.5e3`, `0.1` |
| | `string` | `'текст'`, `"текст"` |
| Складені | `array` | `[1, 2, 3]`, `['name' => 'Ігор']` |
| | `object` | `new DateTime()` |
| | `callable` | назва функції, анонімна функція |
| | `iterable` | масив або об'єкт, який можна перебрати `foreach` |
| Спеціальні | `null` | `null` — «значення відсутнє» |
| | `resource` | дескриптор відкритого файлу чи з'єднання (застарілий механізм) |

### Як дізнатися тип

```php
$x = 3.0;

var_dump($x);         // float(3)
echo gettype($x);     // double (історична назва float)
echo get_debug_type($x); // float — сучасна функція PHP 8, повертає назви як у типах

is_int($x);      // false
is_float($x);    // true
is_numeric('42');   // true — рядок, що містить число
is_numeric('42abc'); // false
is_string($x);   // false
is_array($x);    // false
is_null($x);     // false
```

### Особливості чисел

```php
var_dump(10 / 4);       // float(2.5) — ділення завжди може дати float
var_dump(10 / 5);       // int(2)
var_dump(intdiv(10, 4)); // int(2) — цілочисельне ділення
var_dump(10 % 4);       // int(2) — остача від ділення
var_dump(2 ** 10);      // int(1024) — піднесення до степеня

var_dump(0.1 + 0.2 == 0.3); // bool(false)!
var_dump(round(0.1 + 0.2, 2) == 0.3); // bool(true)

var_dump(PHP_INT_MAX + 1); // float(9.223372036854776E+18) — переповнення int переходить у float
```

:::caution[Гроші і float]
Числа з плаваючою крапкою зберігаються у двійковому вигляді з похибкою (як і в JavaScript). Для грошових сум не використовуйте `float` у розрахунках «як є»: зберігайте суму в **копійках як `int`** (`19950` замість `199.50`) або округлюйте результат `round($sum, 2)` перед виведенням. У базі даних для грошей — тип `DECIMAL`.
:::

### `null`

Значення `null` має змінна, якій присвоєно `null`, якої не існує, або яку видалено через `unset()`. Його використовують для позначення «значення немає»: пошуковий запит не задано, пост не знайдено тощо.

## 3. Приведення типів і порівняння

### Автоматичне приведення (type juggling)

Коли оператор очікує певний тип, PHP автоматично перетворює значення:

```php
var_dump('5' + 3);      // int(8)    — рядок перетворено на число
var_dump('2.5' * 2);    // float(5)
var_dump(5 . 3);        // string(2) "53" — оператор . перетворює на рядок
var_dump('10 яблук' + 5); // int(15) + Warning: A non-numeric value...
var_dump('яблука' + 5);   // TypeError: Unsupported operand types (PHP 8)
```

### Явне приведення (casting)

```php
$age = (int) '19';          // 19
$price = (float) '199.50';  // 199.5
$flag = (bool) 'false';     // true! — непорожній рядок
$text = (string) 42;        // "42"
$list = (array) 'один';     // ['один']

$n = intval('0x1A', 16);    // 26 — з системою числення
```

### Що вважається `false`

При приведенні до `bool` **хибними** (falsy) вважаються лише:

| Значення | Тип |
|---|---|
| `false` | bool |
| `0`, `-0` | int |
| `0.0`, `-0.0` | float |
| `''` (порожній рядок) і `'0'` (рядок з нулем!) | string |
| `[]` (порожній масив) | array |
| `null` | null |

Усе інше — `true`, зокрема `'false'`, `' '` (пробіл), `'0.0'`, `[0]`.

:::caution[Пастка рядка '0']
У JavaScript рядок `'0'` істинний, а в PHP — **хибний**. Тому перевірка `if ($_POST['quantity'])` не пропустить кількість «0», а `if (!$title)` вважатиме заголовок «0» порожнім. Для перевірки на порожній рядок порівнюйте явно: `$title === ''`.
:::

### `==` проти `===`

| Оператор | Назва | Порівнює |
|---|---|---|
| `==` | нестроге (loose) | значення **після** приведення типів |
| `===` | строге (strict) | значення **і** тип, без приведення |
| `!=`, `<>` | нестроге «не дорівнює» | |
| `!==` | строге «не дорівнює» | |

```php
var_dump(1 == '1');      // true
var_dump(1 === '1');     // false — int і string
var_dump(null == false); // true
var_dump(null === false); // false
var_dump([] == false);   // true
var_dump('abc' == 0);    // false у PHP 8 (true у PHP 7!)
var_dump('1e3' == '1000'); // true — обидва рядки схожі на числа, порівнюються як числа
```

У PHP 8 змінилося порівняння рядка з числом: якщо рядок **не є числовим**, число перетворюється на рядок, а не навпаки. Тому `'abc' == 0` тепер `false`. Проте нестроге порівняння все одно містить сюрпризи.

:::tip[Правило]
**Завжди використовуйте `===` і `!==`**, якщо немає конкретної причини для нестрогого порівняння. Так само функції пошуку: `in_array($x, $list, true)` — третій аргумент вмикає строге порівняння.
:::

### `declare(strict_types=1)`

За замовчуванням, якщо функція очікує `int`, а ви передаєте `'5'`, PHP мовчки перетворить рядок на число. Директива на **першому рядку файлу** вмикає строгий режим для викликів функцій у цьому файлі:

```php
<?php
declare(strict_types=1);

function square(int $n): int
{
    return $n * $n;
}

echo square(5);    // 25
echo square('5');  // TypeError: square(): Argument #1 ($n) must be of type int, string given
```

У нашому курсі всі файли з логікою починаються з `declare(strict_types=1);` — помилки типів виявляються одразу, а не перетворюються на тихі баги. Детально про типи параметрів — на наступній лекції.

## 4. Рядки

### Одинарні й подвійні лапки

| | `'одинарні'` | `"подвійні"` |
|---|---|---|
| Підстановка змінних | ні | так: `"Привіт, $name"` |
| Escape-послідовності | лише `\'` і `\\` | `\n`, `\t`, `\"`, `\$`, `\\`, `\u{1F600}` |
| Коли використовувати | звичайний текст без змінних | текст зі змінними або спецсимволами |

```php
$name = 'Ігор';
$items = 3;

echo 'Привіт, $name\n';   // Привіт, $name\n — буквально
echo "Привіт, $name\n";   // Привіт, Ігор + перенос рядка

// Фігурні дужки — для складних виразів і щоб відділити ім'я змінної від тексту
$user = ['name' => 'Ігор', 'city' => 'Львів'];
echo "Місто: {$user['city']}";          // Місто: Львів
echo "У кошику {$items}шт.";            // без дужок PHP шукав би змінну $itemsшт
```

### Конкатенація

Рядки з'єднуються оператором **крапка** `.` (а не `+`, як у JS!):

```php
$first = 'Тарас';
$last = 'Шевченко';
$full = $first . ' ' . $last;
$full .= ' (1814–1861)';     // скорочене додавання до рядка
```

:::caution[Типова помилка після JavaScript]
`'Сума: ' + $sum` у PHP — це **арифметичне** додавання. PHP спробує перетворити `'Сума: '` на число і викине `TypeError`. Для рядків — лише `.`.
:::

### Heredoc і nowdoc

Для довгих багаторядкових рядків:

```php
$title = 'Новий пост';
$author = 'Оля';

// heredoc — як подвійні лапки (зі змінними)
$html = <<<HTML
    <article>
        <h2>{$title}</h2>
        <p>Автор: {$author}</p>
    </article>
    HTML;

// nowdoc — як одинарні лапки (без підстановки)
$code = <<<'TXT'
    Змінна $title тут не підставляється.
    TXT;
```

Відступ закриваючого маркера (`HTML;`) визначає, скільки пробілів буде видалено з початку кожного рядка (PHP 7.3+).

### Рядки і UTF-8: функції `mb_*`

Рядок у PHP — це **послідовність байтів**. Стандартні функції `strlen`, `substr`, `strtoupper` працюють з байтами і **ламають кирилицю**, де одна літера займає 2 байти:

```php
$city = 'Київ';

echo strlen($city);          // 8 — байти!
echo mb_strlen($city);       // 4 — символи

echo substr($city, 0, 3);    // "К�" — розрізали літеру навпіл
echo mb_substr($city, 0, 3); // "Киї"

echo strtoupper($city);      // "Київ" — кирилиця не змінилася
echo mb_strtoupper($city);   // "КИЇВ"
```

| Задача | Байтова функція | Багатобайтова (для UTF-8) |
|---|---|---|
| Довжина | `strlen` | `mb_strlen` |
| Підрядок | `substr` | `mb_substr` |
| Регістр | `strtolower`, `strtoupper` | `mb_strtolower`, `mb_strtoupper` |
| Пошук позиції | `strpos`, `stripos` | `mb_strpos`, `mb_stripos` |
| Перша літера велика | `ucfirst` | `mb_convert_case($s, MB_CASE_TITLE)` (для всіх слів) |

Функції, що працюють з цілими підрядками, безпечні для UTF-8 у будь-якому варіанті: `str_contains`, `str_starts_with`, `str_ends_with`, `str_replace`, `explode`, `implode`, `trim` (для звичайних пробілів).

### Корисні рядкові функції

```php
$s = '  Привіт, PHP!  ';

trim($s);                       // 'Привіт, PHP!' — прибрати пробіли з країв
str_contains($s, 'PHP');        // true (PHP 8)
str_starts_with('index.php', 'index'); // true
str_replace('PHP', 'світе', $s); // заміна
explode(',', 'php,js,css');     // ['php', 'js', 'css'] — рядок → масив
implode(' | ', ['a', 'b']);     // 'a | b' — масив → рядок
str_repeat('=', 10);            // '=========='
sprintf('%05.2f грн', 7.5);     // '07.50 грн' — форматування
number_format(1234567.891, 2, ',', ' '); // '1 234 567,89'
nl2br("Рядок 1\nРядок 2");      // вставляє <br> перед переносами
```

## 5. Масиви

Масив у PHP — універсальна структура: це водночас список, словник (map), стек і черга. Технічно — **впорядкована хеш-таблиця**: пари «ключ ⇒ значення», де ключ — `int` або `string`.

### Індексовані масиви

```php
$langs = ['PHP', 'JavaScript', 'Python'];
echo $langs[0];        // PHP
$langs[] = 'Go';       // додати в кінець
echo count($langs);    // 4
```

### Асоціативні масиви

```php
$post = [
    'id'     => 1,
    'title'  => 'Перший пост',
    'author' => 'Оля',
    'tags'   => ['php', 'новини'],
];

echo $post['title'];          // Перший пост
echo $post['tags'][1];        // новини
$post['views'] = 0;           // додати новий ключ
unset($post['views']);        // видалити ключ

echo $post['likes'];          // Warning: Undefined array key "likes"
echo $post['likes'] ?? 0;     // 0 — безпечне читання з типовим значенням
```

Асоціативний масив — це аналог об'єкта-літерала `{ id: 1, title: '...' }` у JavaScript. Саме такими масивами ми представлятимемо пости в «Міні-блозі».

### Багатовимірні масиви

```php
$posts = [
    ['id' => 1, 'title' => 'Вступ до PHP', 'views' => 120],
    ['id' => 2, 'title' => 'Масиви',       'views' => 75],
    ['id' => 3, 'title' => 'Функції',      'views' => 210],
];

echo $posts[2]['title']; // Функції

foreach ($posts as $post) {
    echo "{$post['id']}. {$post['title']} ({$post['views']} переглядів)\n";
}
```

### Деструктуризація

```php
[$first, $second] = ['PHP', 'JS'];
['title' => $title, 'views' => $views] = $posts[0];

// обмін значень без тимчасової змінної
[$a, $b] = [$b, $a];

// розпакування масиву в масив (spread)
$all = [...$langs, 'Rust'];
```

### Найважливіші функції для масивів

| Функція | Призначення |
|---|---|
| `count($a)` | кількість елементів |
| `in_array($v, $a, true)` | чи є значення (строге порівняння) |
| `array_key_exists($k, $a)` / `isset($a[$k])` | чи є ключ (`isset` дає `false` для значення `null`) |
| `array_keys($a)`, `array_values($a)` | ключі / значення |
| `array_column($rows, 'title')` | витягти один стовпець з масиву записів |
| `array_push`, `array_pop`, `array_shift`, `array_unshift` | стек / черга |
| `array_merge($a, $b)` | об'єднати масиви |
| `array_slice($a, 0, 5)` | частина масиву |
| `array_search($v, $a, true)` | ключ знайденого значення або `false` |
| `sort`, `rsort`, `asort`, `ksort`, `usort` | сортування (змінюють масив на місці!) |
| `array_sum`, `max`, `min` | агрегати |
| `array_map`, `array_filter`, `array_reduce` | функціональна обробка (наступна лекція) |

```php
$titles = array_column($posts, 'title');       // ['Вступ до PHP', 'Масиви', 'Функції']
$totalViews = array_sum(array_column($posts, 'views')); // 405
```

:::note
Функції сортування `sort()`, `usort()` тощо **змінюють сам масив** і повертають `true`, а не відсортований масив. Помилка `$sorted = sort($list);` дає в `$sorted` значення `true`.
:::

## 6. Оператори

### Арифметичні та присвоєння

| Оператор | Дія | Приклад |
|---|---|---|
| `+ - * /` | базові операції | `$a + $b` |
| `%` | остача від ділення | `7 % 3` → `1` |
| `**` | степінь | `2 ** 3` → `8` |
| `++ --` | інкремент / декремент | `$i++`, `--$i` |
| `= += -= *= /= %= **= .=` | присвоєння | `$total += $price` |

### Порівняння

| Оператор | Значення |
|---|---|
| `===`, `!==` | строга рівність / нерівність |
| `==`, `!=` | нестрога рівність / нерівність |
| `<`, `>`, `<=`, `>=` | більше / менше |
| `<=>` | «космічний корабель» (spaceship): повертає `-1`, `0` або `1` |

```php
echo 1 <=> 2;         // -1
echo 'б' <=> 'а';     // 1
echo [1, 2] <=> [1, 3]; // -1 — масиви порівнюються поелементно
```

Оператор `<=>` створений для функцій порівняння в `usort()` — ми використаємо його для сортування постів.

### Логічні

| Оператор | Значення |
|---|---|
| `&&` | І |
| `\|\|` | АБО |
| `!` | НЕ |
| `and`, `or`, `xor` | те саме, але з **нижчим пріоритетом**, ніж `=` |

```php
$result = true and false; // $result === true! Спочатку виконалось присвоєння
$result = true && false;  // $result === false
```

Використовуйте лише `&&`, `||`, `!` — словесні оператори через пріоритет є джерелом помилок.

### Оператори роботи з `null`

```php
// ?? — null coalescing: ліва частина, якщо вона існує і не null, інакше права
$page = $_GET['page'] ?? 1;          // без Warning, навіть якщо ключа немає
$name = $user['name'] ?? $user['login'] ?? 'Гість';

// ??= — присвоїти, якщо змінна не існує або null
$config['per_page'] ??= 10;

// ?: — «Елвіс»: ліва частина, якщо вона truthy, інакше права
$title = $input ?: 'Без назви';  // порожній рядок і '0' теж замінить!

// ?-> — nullsafe: викликати метод, якщо об'єкт не null (з ООП, лекція 11)
$city = $user?->getAddress()?->city;
```

| Вираз | Значення `$x` не існує | `null` | `''` | `'0'` | `'abc'` |
|---|---|---|---|---|---|
| `$x ?? 'def'` | `'def'` | `'def'` | `''` | `'0'` | `'abc'` |
| `$x ?: 'def'` | Warning, `'def'` | `'def'` | `'def'` | `'def'` | `'abc'` |

### Тернарний оператор

```php
$status = $age >= 18 ? 'повнолітній' : 'неповнолітній';
```

Вкладені тернарні оператори без дужок у PHP 8 заборонені (це помилка компіляції) — використовуйте `match`.

### Пріоритет операторів (від вищого)

`**` → `++ --` і приведення типів → `!` → `* / %` → `+ -` → `.` (з PHP 8 — нижче за `+ -`) → `<< >>` → `< <= > >=` → `== != === !== <=>` → `&&` → `||` → `??` → `? :` → `= += ...` → `and` → `xor` → `or`.

Якщо сумніваєтесь — ставте дужки. Код читають частіше, ніж пишуть.

## 7. Керуючі конструкції: розгалуження

### `if` / `elseif` / `else`

```php
$grade = 87;

if ($grade >= 90) {
    $mark = 'A';
} elseif ($grade >= 75) {
    $mark = 'B';
} elseif ($grade >= 60) {
    $mark = 'C';
} else {
    $mark = 'F';
}
```

Альтернативний синтаксис для шаблонів:

```php
<?php if ($posts === []): ?>
    <p>Постів ще немає.</p>
<?php else: ?>
    <p>Усього постів: <?= count($posts) ?></p>
<?php endif; ?>
```

### `switch`

```php
switch ($day) {
    case 'сб':
    case 'нд':
        $type = 'вихідний';
        break;
    default:
        $type = 'робочий';
}
```

Недоліки `switch`: нестроге порівняння `==`, легко забути `break` (виконання «провалиться» в наступний `case`), це інструкція, а не вираз.

### `match` (PHP 8)

`match` — **вираз**, що повертає значення, порівнює **строго** (`===`) і не потребує `break`:

```php
$type = match ($day) {
    'сб', 'нд' => 'вихідний',
    'пн', 'вт', 'ср', 'чт', 'пт' => 'робочий',
};

$label = match ($sort) {
    'old'   => 'Спочатку старі',
    'title' => 'За назвою',
    default => 'Спочатку нові',
};
```

Якщо жодна гілка не підійшла і немає `default`, `match` викидає `UnhandledMatchError` — це краще, ніж мовчки отримати `null`.

Прийом `match (true)` замінює ланцюжок `if/elseif`:

```php
$mark = match (true) {
    $grade >= 90 => 'A',
    $grade >= 75 => 'B',
    $grade >= 60 => 'C',
    default      => 'F',
};
```

| | `switch` | `match` |
|---|---|---|
| Порівняння | `==` (нестроге) | `===` (строге) |
| Повертає значення | ні (інструкція) | так (вираз) |
| `break` | потрібен | не потрібен |
| Кілька значень в одній гілці | кілька `case` | через кому |
| Немає збігу | нічого не відбувається | `UnhandledMatchError` |

## 8. Цикли

### `for`, `while`, `do-while`

```php
for ($i = 1; $i <= 5; $i++) {
    echo $i * $i, ' ';           // 1 4 9 16 25
}

$n = 100;
while ($n > 1) {
    $n = intdiv($n, 2);
}

do {
    $code = random_int(1000, 9999);  // криптографічно стійке випадкове число
} while ($code % 10 === 0);          // тіло виконається хоча б раз
```

### `foreach` — головний цикл для масивів

```php
$prices = ['Хліб' => 32.5, 'Молоко' => 45.9, 'Сир' => 120.0];

// лише значення
foreach ($prices as $price) {
    echo $price, PHP_EOL;
}

// ключ і значення
foreach ($prices as $product => $price) {
    echo "$product: " . number_format($price, 2) . " грн\n";
}

// зміна елементів масиву — через посилання
foreach ($prices as &$price) {
    $price = round($price * 1.1, 2);  // +10%
}
unset($price); // ОБОВ'ЯЗКОВО розірвати посилання після циклу
```

:::danger[Пастка foreach за посиланням]
Після `foreach ($arr as &$v)` змінна `$v` залишається посиланням на **останній елемент**. Якщо потім використати `$v` у наступному `foreach` без `&`, ви непомітно перезапишете останній елемент масиву. Тому одразу після циклу — `unset($v)`. Ще краще — уникати посилань і будувати новий масив (`array_map`).
:::

### `break` і `continue`

```php
foreach ($posts as $post) {
    if ($post['views'] < 100) {
        continue;      // перейти до наступної ітерації
    }
    if ($post['id'] > 10) {
        break;         // вийти з циклу
    }
    echo $post['title'];
}
```

`break 2` виходить одразу з двох вкладених циклів.

### Альтернативний синтаксис у шаблонах

```php
<ul>
    <?php foreach ($posts as $post): ?>
        <li><?= $post['title'] ?> — <?= $post['views'] ?> переглядів</li>
    <?php endforeach; ?>
</ul>
```

:::caution[Безпека виведення]
Виведення `<?= $post['title'] ?>` безпечне, лише поки дані беремо з нашого власного коду. Щойно дані надходять від користувача (форма, URL), їх **обов'язково** треба екранувати функцією `htmlspecialchars()` — інакше зловмисник вставить на сторінку власний JavaScript (атака XSS). Ми розберемо це на практичних 6–7.
:::

## Підсумки

- Змінні починаються з `$`, чутливі до регістру, тип визначається значенням. Масиви копіюються при присвоєнні (copy-on-write), а не передаються за посиланням, як у JS.
- Константи — `const NAME = ...` (переважно) або `define()`; магічні константи `__DIR__`, `__FILE__`.
- Типи: `bool`, `int`, `float`, `string`, `array`, `object`, `callable`, `null`. Перевірка — `is_*()`, `get_debug_type()`, `var_dump()`.
- Falsy-значення: `false`, `0`, `0.0`, `''`, **`'0'`**, `[]`, `null`. Порівнюйте строго: `===`, `in_array(..., true)`. У файлах логіки — `declare(strict_types=1)`.
- Рядки: одинарні лапки — буквально, подвійні — з інтерполяцією; конкатенація — `.`; для кирилиці — функції `mb_*`.
- Масиви — впорядковані хеш-таблиці: індексовані, асоціативні, багатовимірні; `array_column`, `in_array`, `count`, сортування змінює масив на місці.
- Оператори `??`, `??=` для безпечної роботи з відсутніми значеннями; `<=>` для сортування; уникайте `and`/`or`.
- `match` — строгий вираз-розгалуження без `break`; `foreach` — основний цикл для масивів; після `foreach` за посиланням — `unset()`.
