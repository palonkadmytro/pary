## 1. Навіщо потрібні функції

**Функція** (function) — іменований блок коду, який виконує певну задачу і може бути викликаний багато разів.

Без функцій код швидко перетворюється на «простирадло», де одні й ті самі рядки повторюються з дрібними змінами. Функції дають:

- **Повторне використання** (DRY — Don't Repeat Yourself): написали раз — викликаємо скільки завгодно.
- **Абстракцію**: щоб використати `formatMoney(1250)`, не треба знати, як саме форматуються гроші.
- **Декомпозицію**: велику задачу розбиваємо на маленькі зрозумілі кроки — `validate()`, `calculate()`, `render()`.
- **Тестованість**: невелику функцію легко перевірити окремо.
- **Читабельність**: добре названа функція — це документація.

Ви вже користувалися вбудованими функціями: `console.log()`, `Number()`, `Math.round()`, `prompt()`. Тепер навчимося писати власні.

## 2. Оголошення та виклик функції

### Оголошення функції (function declaration)

```js
function greet(name) {
  console.log(`Привіт, ${name}!`);
}
```

Складові:

| Частина | У прикладі | Опис |
|---|---|---|
| Ключове слово | `function` | починає оголошення |
| Ім'я | `greet` | дієслово в camelCase: `getTotal`, `renderList`, `isValid` |
| Параметри | `(name)` | вхідні змінні, через кому; можуть бути відсутні — `()` |
| Тіло | `{ ... }` | код, що виконується під час виклику |

### Виклик

Оголошення лише **описує** функцію. Щоб вона спрацювала, її треба **викликати** — ім'я плюс круглі дужки:

```js
greet('Олена');   // Привіт, Олена!
greet('Тарас');   // Привіт, Тарас!

greet;            // без дужок — це сама функція (значення), а не виклик
```

### Підняття оголошень

Оголошення функцій **піднімаються** (hoisting) повністю — функцію можна викликати **до** рядка, де вона оголошена:

```js
showTotal(250); // працює

function showTotal(sum) {
  console.log(`Разом: ${sum} грн`);
}
```

Це зручно: на початку файлу можна записати «сценарій» програми, а нижче — деталі. Для функціональних виразів і стрілкових функцій це **не працює** (розділ 5).

## 3. Параметри та аргументи

**Параметри** (parameters) — імена в оголошенні функції. **Аргументи** (arguments) — конкретні значення, передані під час виклику.

```js
function rectangleArea(width, height) {  // width, height — параметри
  return width * height;
}

rectangleArea(5, 3);                      // 5 і 3 — аргументи
```

### Кількість аргументів

JavaScript не перевіряє кількість аргументів:

```js
rectangleArea(5);        // NaN — height === undefined, 5 * undefined
rectangleArea(5, 3, 10); // 15 — зайвий аргумент ігнорується
```

### Значення за замовчуванням

Параметр отримує значення за замовчуванням (default parameter), якщо аргумент не передано або передано `undefined`:

```js
function formatPrice(amount, currency = 'грн', digits = 2) {
  return `${amount.toFixed(digits)} ${currency}`;
}

formatPrice(99.5);              // '99.50 грн'
formatPrice(99.5, '$');         // '99.50 $'
formatPrice(99.5, undefined, 0); // '100 грн' — undefined → за замовчуванням
formatPrice(99.5, null);        // '99.50 null' — null НЕ замінюється!
```

Значення за замовчуванням обчислюється під час кожного виклику і може залежати від попередніх параметрів: `function f(a, b = a * 2) {}`.

### Rest-параметри

Rest-параметр `...name` збирає всі «зайві» аргументи в **масив**. Він має бути останнім:

```js
function sum(...numbers) {
  let total = 0;
  for (const n of numbers) {
    total += n;
  }
  return total;
}

sum();              // 0
sum(5);             // 5
sum(1, 2, 3, 4);    // 10

function logWithPrefix(prefix, ...messages) {
  for (const m of messages) {
    console.log(`[${prefix}] ${m}`);
  }
}
logWithPrefix('INFO', 'Старт', 'Дані завантажено');
```

Протилежна операція — **spread** `...` під час виклику — «розгортає» масив в окремі аргументи:

```js
const marks = [78, 95, 88];
Math.max(...marks); // 95 — те саме, що Math.max(78, 95, 88)
```

:::note[Об'єкт arguments]
У старому коді можна побачити `arguments` — псевдомасив усіх аргументів функції. У стрілкових функціях його немає. Сучасна заміна — rest-параметри.
:::

### Передавання примітивів і об'єктів

Аргументи передаються **за значенням**, але для об'єктів значенням є **посилання**:

```js
function increase(n) {
  n = n + 1;          // змінюємо локальну копію
}
let count = 5;
increase(count);
console.log(count);   // 5 — без змін

function rename(user) {
  user.name = 'Нове ім\'я'; // змінюємо об'єкт за посиланням
}
const student = { name: 'Олена' };
rename(student);
console.log(student.name); // 'Нове ім'я' — об'єкт змінився!
```

Функція, яка непомітно змінює переданий об'єкт, — джерело важких для пошуку помилок. Краще повертати новий об'єкт (розділ 8 і лекція 6).

### Іменовані параметри через об'єкт

Коли параметрів більше трьох, виклик `createUser('Олена', 19, true, false, 'uk')` стає нечитабельним. Прийом — передавати **один об'єкт** і деструктурувати його в параметрах:

```js
function createUser({ name, age, isAdmin = false, lang = 'uk' }) {
  return { name, age, isAdmin, lang };
}

createUser({ name: 'Олена', age: 19, lang: 'en' });
```

Порядок властивостей не важливий, а виклик сам себе документує. Деструктуризацію розберемо на лекції 6.

## 4. Повернення значення

Інструкція `return` **завершує** функцію і **повертає** значення в місце виклику:

```js
function calcVat(price, rate = 0.2) {
  return price * rate;
}

const vat = calcVat(1000);                 // 200
const total = 1000 + calcVat(1000);        // 1200
console.log(`ПДВ: ${calcVat(500)} грн`);   // ПДВ: 100 грн
```

Особливості:

- Функція без `return` (або з порожнім `return;`) повертає `undefined`.
- Код після `return` не виконується.
- Повернути можна лише **одне** значення; щоб повернути кілька — об'єкт або масив.
- `return` можна використовувати кілька разів — для раннього виходу.

```js
function getGrade(score) {
  if (typeof score !== 'number' || Number.isNaN(score)) return null;
  if (score >= 90) return 'A';
  if (score >= 75) return 'B';
  if (score >= 60) return 'C';
  return 'F';
}

function minMax(numbers) {
  return { min: Math.min(...numbers), max: Math.max(...numbers) };
}
const { min, max } = minMax([4, 9, 1]); // min = 1, max = 9
```

### console.log чи return

Початківці часто плутають **виведення** і **повернення**:

```js
function addLog(a, b) {
  console.log(a + b);   // лише показує в консолі
}
function add(a, b) {
  return a + b;         // повертає значення для подальшої роботи
}

const r1 = addLog(2, 3); // у консолі 5, але r1 === undefined
const r2 = add(2, 3);    // r2 === 5, можна використати далі
```

Правило: функція, що **обчислює**, має **повертати** результат. Виведення — окрема відповідальність окремої функції.

## 5. Функціональні вирази та стрілкові функції

У JavaScript функції — **значення першого класу** (first-class citizens): їх можна присвоювати змінним, передавати як аргументи, повертати з інших функцій, зберігати в масивах і об'єктах.

### Функціональний вираз (function expression)

```js
const square = function (x) {
  return x * x;
};

square(4); // 16
```

На відміну від оголошення, функціональний вираз **не піднімається**: до рядка присвоєння змінна `square` перебуває в TDZ.

```js
cube(2);   // ReferenceError: Cannot access 'cube' before initialization
const cube = function (x) { return x ** 3; };
```

### Стрілкова функція (arrow function)

Скорочений синтаксис, що з'явився в ES2015:

```js
// Повна форма
const add = (a, b) => {
  return a + b;
};

// Якщо тіло — один вираз, фігурні дужки й return можна опустити
const add2 = (a, b) => a + b;

// Один параметр — дужки навколо нього необов'язкові (Prettier їх додасть)
const double = (n) => n * 2;

// Без параметрів — порожні дужки обов'язкові
const getYear = () => new Date().getFullYear();

// Повернення об'єкта в короткій формі — обгорнути в дужки!
const makePoint = (x, y) => ({ x, y });
```

:::caution[Об'єкт у короткій стрілковій функції]
```js
const make = () => { name: 'A' };   // undefined! { } сприйняті як тіло функції
const make2 = () => ({ name: 'A' }); // правильно
```
:::

### Порівняння способів

| | Declaration | Expression | Arrow |
|---|---|---|---|
| Синтаксис | `function f() {}` | `const f = function () {}` | `const f = () => {}` |
| Підняття (виклик до оголошення) | так | ні | ні |
| Власний `this` | так | так | ні — бере `this` з оточення |
| `arguments` | так | так | ні |
| Можна викликати з `new` | так | так | ні |
| Типове використання | основні функції модуля | рідко | колбеки, короткі функції |

`this` ми розглянемо на лекції 6 у зв'язку з методами об'єктів. Поки що практичне правило: **основні іменовані функції — через `function`, короткі колбеки — стрілкові.**

## 6. Область видимості і замикання

### Локальні та глобальні змінні

Змінні, оголошені всередині функції, — **локальні**: вони існують лише під час виконання функції і не видимі зовні. Параметри теж локальні.

```js
const appName = 'Трекер';        // глобальна

function showTitle() {
  const title = `${appName} v1`; // локальна; бачить зовнішню appName
  console.log(title);
}

showTitle();
console.log(title); // ReferenceError
```

### Лексична область видимості

**Лексична область видимості** (lexical scope): функція бачить змінні того місця, **де її написали**, а не того, де викликали. Пошук змінної йде «зсередини назовні» — від поточної області до глобальної (**ланцюжок областей видимості**, scope chain).

```js
const level = 'глобальний';

function outer() {
  const level = 'зовнішній';

  function inner() {
    console.log(level); // 'зовнішній' — найближча за вкладеністю
  }

  inner();
}

outer();
```

Якщо локальна змінна має ту саму назву, що й зовнішня, вона її **затінює** (shadowing). Цього краще уникати — плутає читача.

:::caution[Мінімум глобальних змінних]
Глобальні змінні доступні всьому коду на сторінці (і всім підключеним скриптам). Будь-яка функція може їх випадково змінити. Тримайте дані якомога локальніше, передавайте у функції через параметри й отримуйте через `return`.
:::

### Замикання (closure)

**Замикання** — функція разом із «запам'ятованими» змінними зовнішньої області, у якій вона була створена. Вкладена функція має доступ до змінних зовнішньої **навіть після того, як зовнішня функція завершилась**.

```js
function createCounter() {
  let count = 0;              // «приватна» змінна

  return function () {
    count++;
    return count;
  };
}

const counterA = createCounter();
const counterB = createCounter();

counterA(); // 1
counterA(); // 2
counterA(); // 3
counterB(); // 1 — у кожного лічильника власна count

console.log(count); // ReferenceError — ззовні недоступна
```

Що відбувається: кожен виклик `createCounter()` створює нову змінну `count` і нову внутрішню функцію, яка тримає посилання на неї. Поки існує `counterA`, існує і «її» `count`.

Практичні застосування замикань:

- **Приватний стан** — дані, які не можна змінити ззовні інакше, ніж через функцію.
- **Фабрики функцій** — створення налаштованих функцій:

  ```js
  function createFormatter(currency) {
    return (amount) => `${amount.toFixed(2)} ${currency}`;
  }
  const toUah = createFormatter('грн');
  const toUsd = createFormatter('$');
  toUah(15);  // '15.00 грн'
  toUsd(3.5); // '3.50 $'
  ```

- **Обробники подій** (лекція 9), які пам'ятають дані з моменту створення.

## 7. Функції як значення: колбеки і функції вищого порядку

**Колбек** (callback, функція зворотного виклику) — функція, яку передають іншій функції як аргумент, щоб та викликала її у потрібний момент.

**Функція вищого порядку** (higher-order function) — функція, що приймає іншу функцію як аргумент або повертає функцію. `createCounter` і `createFormatter` вище — функції вищого порядку.

```js
// repeat — функція вищого порядку, action — колбек
function repeat(times, action) {
  for (let i = 1; i <= times; i++) {
    action(i);
  }
}

repeat(3, (i) => console.log(`Крок ${i}`));
// Крок 1, Крок 2, Крок 3

// Можна передати і заздалегідь оголошену функцію — БЕЗ дужок
function shout(i) {
  console.log(`КРОК ${i}!`);
}
repeat(2, shout);       // правильно: передаємо функцію
// repeat(2, shout());  // помилка: передаємо результат виклику (undefined)
```

Колбеки — основа JavaScript. Ви будете зустрічати їх постійно:

```js
// Відкладений виклик (через 1 секунду)
setTimeout(() => console.log('Минула секунда'), 1000);

// Методи масивів (лекція 6)
const prices = [100, 250, 40];
prices.forEach((p) => console.log(p));
const withVat = prices.map((p) => p * 1.2);   // [120, 300, 48]
const cheap = prices.filter((p) => p < 200);  // [100, 40]

// Обробники подій (лекція 9)
button.addEventListener('click', () => console.log('Клік!'));
```

Напишемо власний аналог `filter`, щоб побачити, як це працює зсередини:

```js
function filterArray(items, predicate) {
  const result = [];
  for (const item of items) {
    if (predicate(item)) {      // викликаємо колбек для кожного елемента
      result.push(item);
    }
  }
  return result;
}

const isEven = (n) => n % 2 === 0;
filterArray([1, 2, 3, 4, 5, 6], isEven);          // [2, 4, 6]
filterArray(['кіт', 'собака', 'їжак'], (w) => w.length > 3); // ['собака', 'їжак']
```

Функція `filterArray` нічого не знає про те, **як** відбирати елементи, — це вирішує колбек. Така гнучкість — головна перевага функцій вищого порядку.

## 8. Чисті функції, побічні ефекти, рекурсія

### Чисті функції

**Чиста функція** (pure function):

1. За однакових аргументів **завжди** повертає однаковий результат.
2. Не має **побічних ефектів** (side effects): не змінює зовнішні змінні й аргументи, не виводить у консоль, не змінює DOM, не робить запитів.

```js
// Чиста
function applyDiscount(price, percent) {
  return price - (price * percent) / 100;
}

// Нечиста: залежить від зовнішньої змінної і змінює її
let balance = 1000;
function spend(amount) {
  balance -= amount;     // побічний ефект
  return balance;
}

// Нечиста: результат залежить від часу
function greeting() {
  return new Date().getHours() < 12 ? 'Доброго ранку' : 'Добрий день';
}
```

| | Чисті функції | Функції з побічними ефектами |
|---|---|---|
| Передбачуваність | висока | залежить від стану програми |
| Тестування | просте: вхід → вихід | потрібно готувати середовище |
| Приклади | обчислення, форматування, фільтрація | виведення, DOM, мережа, сховище |

Програма без побічних ефектів нічого корисного не зробить — їй треба щось показати користувачеві. Мета інша: **відокремити** чисті обчислення від побічних ефектів. Наприклад, у трекері витрат ми матимемо чисту `getStats(items)` (рахує) і нечисту `renderStats()` (малює в DOM).

### Рекурсія

**Рекурсія** — виклик функцією самої себе. Кожна рекурсивна функція потребує:

- **базового випадку** (base case) — умови, коли рекурсія зупиняється;
- **рекурсивного кроку**, що наближає до базового випадку.

```js
// n! = n × (n−1) × ... × 1
function factorial(n) {
  if (n <= 1) return 1;          // базовий випадок
  return n * factorial(n - 1);   // рекурсивний крок
}

factorial(5); // 120
```

Як це виконується:

```text
factorial(5) = 5 * factorial(4)
             = 5 * 4 * factorial(3)
             = 5 * 4 * 3 * factorial(2)
             = 5 * 4 * 3 * 2 * factorial(1)
             = 5 * 4 * 3 * 2 * 1 = 120
```

Кожен виклик займає місце в **стеку викликів** (call stack). Без базового випадку стек переповнюється: `RangeError: Maximum call stack size exceeded`.

Рекурсія природна для деревоподібних даних: вкладені коментарі, структура папок, DOM-дерево. Для простих повторень цикл зазвичай ефективніший і зрозуміліший.

### Стек викликів у DevTools

Поставте точку зупинки всередині `factorial` (вкладка Sources) і перезавантажте сторінку. Панель **Call Stack** покаже ланцюжок `factorial ← factorial ← factorial ← ...` — це наочно пояснює, як працює рекурсія.

## 9. Як писати хороші функції

### Іменування

| Тип функції | Шаблон назви | Приклади |
|---|---|---|
| Дія | дієслово + іменник | `renderList`, `saveExpense`, `clearForm` |
| Отримання значення | `get…`, `calc…`, `format…` | `getTotal`, `calcVat`, `formatDate` |
| Перевірка (повертає boolean) | `is…`, `has…`, `can…` | `isValid`, `hasDebt`, `canEdit` |
| Створення | `create…`, `make…` | `createCounter`, `createExpenseItem` |
| Обробник події | `handle…`, `on…` | `handleSubmit`, `onDeleteClick` |

### Принципи

1. **Одна функція — одна задача.** Якщо в назві хочеться написати «і» (`validateAndSave`), функцію варто розділити.
2. **Короткі функції.** Орієнтир — функція вміщується на екран (до 20–30 рядків).
3. **Мало параметрів.** До трьох; більше — передавайте об'єкт.
4. **Ранній вихід** для некоректних даних замість глибокої вкладеності.
5. **Не змінюйте аргументи** — повертайте нові значення.
6. **Документуйте неочевидне** коментарем JSDoc:

```js
/**
 * Обчислює суму з урахуванням знижки.
 * @param {number} price - ціна в гривнях
 * @param {number} [percent=0] - знижка у відсотках (0–100)
 * @returns {number} ціна після знижки, округлена до копійок
 */
function discounted(price, percent = 0) {
  const value = price * (1 - percent / 100);
  return Math.round(value * 100) / 100;
}
```

VS Code показує JSDoc-підказки при наведенні на функцію та під час виклику.

### Типові помилки

| Помилка | Приклад | Виправлення |
|---|---|---|
| Забули викликати | `const t = getTotal;` | `getTotal()` |
| Передали результат замість функції | `setTimeout(tick(), 1000)` | `setTimeout(tick, 1000)` |
| Забули `return` | `function sq(x) { x * x; }` → `undefined` | `return x * x;` |
| `return` з переносом рядка | `return` ↵ `{ ... }` | значення на тому ж рядку |
| `{ }` у короткій стрілці для об'єкта | `() => { a: 1 }` | `() => ({ a: 1 })` |
| Виклик виразу до оголошення | `f(); const f = () => {}` | оголосити вище або `function` |
| Мутація аргументу | `function add(arr, x) { arr.push(x); }` | `return [...arr, x];` |
| Рекурсія без базового випадку | `RangeError` | додати умову виходу |

## Підсумки

- Функція — іменований блок коду для повторного використання; її оголошують і **викликають** дужками.
- Три способи: оголошення (`function f() {}`, піднімається), функціональний вираз і стрілкова функція (не піднімаються; стрілкова не має власного `this`).
- Параметри можуть мати значення за замовчуванням; rest-параметр `...args` збирає аргументи в масив. Об'єкти передаються за посиланням.
- `return` завершує функцію й повертає одне значення; без нього — `undefined`.
- Лексична область видимості: функція бачить змінні місця свого створення. Замикання дозволяє функції пам'ятати ці змінні після завершення зовнішньої функції.
- Функції — значення: їх передають як колбеки у функції вищого порядку (`setTimeout`, `map`, `filter`, `addEventListener`).
- Відокремлюйте чисті обчислення від побічних ефектів. Рекурсія потребує базового випадку.
