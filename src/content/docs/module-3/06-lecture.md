## 1. Об'єкти

**Об'єкт** (object) — набір пар «ключ: значення», які називають **властивостями** (properties). Об'єкт описує одну сутність з кількома характеристиками: студента, товар, витрату.

### Літерал об'єкта

```js
const expense = {
  id: 1,
  title: 'Обід у їдальні',
  amount: 95,
  category: 'Їжа',
  date: '2026-03-02',
  'is paid': true,      // ключ з пробілом — у лапках
};
```

Ключі — рядки (або символи). Лапки потрібні, лише якщо ключ не є коректним ідентифікатором. Кома після останньої властивості (trailing comma) дозволена й зручна для систем контролю версій.

### Доступ до властивостей

```js
// Через крапку — коли ім'я відоме заздалегідь
expense.title;          // 'Обід у їдальні'

// Через квадратні дужки — для ключів з пробілами або обчислюваних ключів
expense['is paid'];     // true
const field = 'amount';
expense[field];         // 95 — значення змінної field використовується як ключ
expense.field;          // undefined — шукає властивість з ім'ям "field"!

// Неіснуюча властивість — undefined (не помилка)
expense.comment;        // undefined
expense.author.name;    // TypeError: Cannot read properties of undefined
expense.author?.name;   // undefined — безпечно
```

### Додавання, зміна, видалення

```js
const student = { name: 'Олена' };

student.course = 2;            // додали нову властивість
student.name = 'Олена Коваль'; // змінили існуючу
delete student.course;         // видалили

console.log(student);          // { name: 'Олена Коваль' }
```

### Перевірка наявності властивості

```js
const settings = { theme: 'dark', limit: 0 };

'limit' in settings;              // true
Object.hasOwn(settings, 'limit'); // true — сучасний спосіб (ES2022)
settings.limit !== undefined;     // true, але не відрізняє «немає» від «undefined»
if (settings.limit) { }           // ПАСТКА: 0 — falsy, умова хибна
```

### Скорочений запис і обчислювані ключі

```js
const title = 'Кава';
const amount = 60;

// Скорочення: якщо ім'я змінної збігається з ключем
const item = { title, amount };        // { title: 'Кава', amount: 60 }

// Обчислюваний ключ у квадратних дужках
const key = 'category';
const item2 = { [key]: 'Їжа' };       // { category: 'Їжа' }

const lang = 'uk';
const labels = { [`title_${lang}`]: 'Назва' }; // { title_uk: 'Назва' }
```

### Вкладені об'єкти

```js
const user = {
  name: 'Тарас',
  address: {
    city: 'Львів',
    street: 'Городоцька',
  },
  hobbies: ['шахи', 'біг'],
};

user.address.city;        // 'Львів'
user.hobbies[1];          // 'біг'
user.contacts?.email;     // undefined — без помилки
```

## 2. Методи об'єкта і this

Значенням властивості може бути функція. Така властивість називається **методом**.

```js
const cart = {
  items: [120, 45, 300],
  discount: 10,

  // Скорочений синтаксис методу
  getTotal() {
    let sum = 0;
    for (const price of this.items) {
      sum += price;
    }
    return sum * (1 - this.discount / 100);
  },
};

cart.getTotal(); // 418.5
```

### Що таке this

`this` — це об'єкт, **перед крапкою** під час виклику методу. У `cart.getTotal()` значення `this` — `cart`. Значення `this` визначається **в момент виклику**, а не в момент оголошення:

```js
const getTotal = cart.getTotal;
getTotal(); // TypeError у строгому режимі: this === undefined
```

Стрілкові функції не мають власного `this` — вони беруть `this` із зовнішнього коду. Тому **стрілкові функції не використовують як методи об'єкта**:

```js
const counter = {
  count: 0,
  incWrong: () => { this.count++; },  // this — не counter!
  inc() { this.count++; },            // правильно
};
```

Зате стрілкові функції зручні **всередині** методів — вони «бачать» `this` методу:

```js
const group = {
  name: 'ІПЗ-21',
  students: ['Олена', 'Тарас'],
  print() {
    this.students.forEach((s) => console.log(`${s} (${this.name})`));
  },
};
```

:::note
Повна тема `this`, класів і прототипів виходить за межі цього модуля. У проєкті «Трекер витрат» ми працюватимемо з простими об'єктами-даними та окремими функціями, тому `this` нам майже не знадобиться.
:::

## 3. Перебір об'єкта

Три статичні методи `Object` повертають **масиви**, з якими далі зручно працювати:

```js
const stats = { 'Їжа': 955.5, 'Транспорт': 480, 'Розваги': 220 };

Object.keys(stats);    // ['Їжа', 'Транспорт', 'Розваги']
Object.values(stats);  // [955.5, 480, 220]
Object.entries(stats); // [['Їжа', 955.5], ['Транспорт', 480], ['Розваги', 220]]

for (const [category, sum] of Object.entries(stats)) {
  console.log(`${category}: ${sum} грн`);
}

// Кількість властивостей
Object.keys(stats).length; // 3

// Зворотне перетворення: масив пар → об'єкт
Object.fromEntries([['a', 1], ['b', 2]]); // { a: 1, b: 2 }
```

Також є `for...in` (лекція 2), але `Object.entries` + `for...of` сучасніший і не захоплює успадковані властивості.

## 4. Посилання і копіювання

Змінна з об'єктом зберігає **посилання** (reference) — «адресу» об'єкта в пам'яті, а не сам об'єкт.

```js
const a = { value: 1 };
const b = a;           // копіюється посилання, об'єкт той самий
b.value = 2;
console.log(a.value);  // 2

const c = { value: 2 };
console.log(b === a);  // true — одне посилання
console.log(c === a);  // false — інший об'єкт, хоч і з тим самим вмістом
```

```text
 a ──┐
     ├──►  { value: 2 }
 b ──┘

 c ─────►  { value: 2 }   (окремий об'єкт)
```

### Поверхнева копія

```js
const original = { title: 'Кава', amount: 60, tags: ['ранок'] };

const copy1 = { ...original };               // spread — найпоширеніше
const copy2 = Object.assign({}, original);   // старіший спосіб

copy1.amount = 70;
console.log(original.amount); // 60 — примітивні властивості скопійовані

copy1.tags.push('офіс');
console.log(original.tags);   // ['ранок', 'офіс'] — вкладений масив спільний!
```

**Поверхнева копія** (shallow copy) копіює лише перший рівень. Вкладені об'єкти й масиви залишаються спільними.

### Глибока копія

```js
const deep = structuredClone(original); // вбудована функція сучасних браузерів
deep.tags.push('вечір');
console.log(original.tags);            // не змінився
```

`structuredClone` копіює вкладені об'єкти, масиви, дати, `Map`, `Set`, але не функції. Старий прийом `JSON.parse(JSON.stringify(obj))` теж працює, але втрачає `undefined`, функції й перетворює дати на рядки.

| Спосіб | Глибина | Коментар |
|---|---|---|
| `b = a` | жодної | те саме посилання |
| `{ ...a }`, `Object.assign` | 1 рівень | достатньо для «плоских» об'єктів |
| `[...arr]`, `arr.slice()` | 1 рівень | для масивів |
| `structuredClone(a)` | повна | рекомендований спосіб глибокої копії |

### Незмінність даних

Часто краще не змінювати об'єкт, а створювати **новий** з потрібними змінами:

```js
const updated = { ...expense, amount: 110 }; // копія з новою сумою
```

Пізніші властивості перекривають попередні. Такий підхід (immutability) спрощує налагодження й буде основою роботи з React.

## 5. Деструктуризація, spread, rest

### Деструктуризація об'єкта

**Деструктуризація** (destructuring) — синтаксис, що «розпаковує» властивості в окремі змінні:

```js
const expense = { id: 3, title: 'Кіно', amount: 220, category: 'Розваги' };

const { title, amount } = expense;
// те саме, що const title = expense.title; const amount = expense.amount;

// Перейменування і значення за замовчуванням
const { category: cat, date = 'сьогодні' } = expense;
console.log(cat, date); // 'Розваги' 'сьогодні'

// Rest — решта властивостей
const { id, ...data } = expense;
console.log(data);      // { title: 'Кіно', amount: 220, category: 'Розваги' }

// Вкладена деструктуризація
const user = { name: 'Тарас', address: { city: 'Львів' } };
const { address: { city } } = user;
```

Особливо зручна в параметрах функцій:

```js
function formatExpense({ title, amount, category = 'Інше' }) {
  return `${title} — ${amount} грн (${category})`;
}
formatExpense(expense);
```

### Деструктуризація масиву

Для масиву важлива **позиція**, а не ім'я:

```js
const rgb = [255, 128, 0];
const [red, green, blue] = rgb;
const [first, , third] = rgb;       // пропуск елемента
const [head, ...tail] = rgb;        // head = 255, tail = [128, 0]

// Обмін значень без третьої змінної
let x = 1, y = 2;
[x, y] = [y, x];

// Пари з Object.entries
for (const [key, value] of Object.entries({ a: 1, b: 2 })) { /* ... */ }
```

### Spread

```js
// Масиви
const a = [1, 2];
const b = [3, 4];
const merged = [...a, ...b, 5];     // [1, 2, 3, 4, 5]
const copy = [...a];

// Об'єкти
const defaults = { theme: 'light', lang: 'uk' };
const userSettings = { theme: 'dark' };
const settings = { ...defaults, ...userSettings }; // { theme: 'dark', lang: 'uk' }

// Рядок → масив символів
[...'Київ'];                         // ['К', 'и', 'ї', 'в']
```

## 6. Масиви: основи

**Масив** (array) — упорядкована колекція значень, доступ до яких здійснюється за **індексом** (з нуля). Масив — особливий вид об'єкта.

```js
const categories = ['Їжа', 'Транспорт', 'Розваги'];
const empty = [];
const mixed = [1, 'два', true, null, { a: 1 }, [5, 6]]; // можливо, але не варто

categories[0];          // 'Їжа'
categories[2];          // 'Розваги'
categories[10];         // undefined
categories.at(-1);      // 'Розваги' — останній елемент (ES2022)
categories.length;      // 3

categories[1] = 'Таксі';  // заміна елемента (навіть якщо масив const)
```

Довжина `length` завжди на одиницю більша за найбільший індекс. Індекс останнього елемента — `length - 1`.

Інші способи створення:

```js
Array.from({ length: 5 }, (_, i) => i * 2); // [0, 2, 4, 6, 8]
Array.from('abc');                           // ['a', 'b', 'c']
new Array(3).fill(0);                        // [0, 0, 0]
Array.of(7);                                 // [7]
```

Перевірка: `Array.isArray(value)` (бо `typeof [] === 'object'`).

## 7. Методи, що змінюють масив

Ці методи **мутують** (змінюють) вихідний масив:

| Метод | Що робить | Повертає |
|---|---|---|
| `push(x, ...)` | додає в кінець | нову довжину |
| `pop()` | видаляє останній | видалений елемент |
| `unshift(x, ...)` | додає на початок | нову довжину |
| `shift()` | видаляє перший | видалений елемент |
| `splice(start, count, ...items)` | видаляє/вставляє/замінює | масив видалених |
| `sort(compareFn)` | сортує на місці | той самий масив |
| `reverse()` | обертає на місці | той самий масив |
| `fill(value)` | заповнює значенням | той самий масив |

```js
const queue = ['Олена', 'Тарас'];
queue.push('Ірина');        // ['Олена', 'Тарас', 'Ірина']
queue.shift();              // 'Олена'; queue = ['Тарас', 'Ірина']
queue.unshift('Марко');     // ['Марко', 'Тарас', 'Ірина']
queue.pop();                // 'Ірина'

const letters = ['a', 'b', 'c', 'd', 'e'];
letters.splice(1, 2);             // видалити 2 елементи з індексу 1 → ['b', 'c']
// letters = ['a', 'd', 'e']
letters.splice(1, 0, 'X', 'Y');   // вставити без видалення
// letters = ['a', 'X', 'Y', 'd', 'e']
letters.splice(-1, 1, 'Z');       // замінити останній
// letters = ['a', 'X', 'Y', 'd', 'Z']
```

### Методи, що НЕ змінюють масив

| Метод | Що повертає |
|---|---|
| `slice(start, end)` | копію частини масиву (end не включно) |
| `concat(arr2)` | новий об'єднаний масив |
| `join(sep)` | рядок з елементів |
| `indexOf(x)`, `lastIndexOf(x)` | індекс або `-1` |
| `includes(x)` | `true` / `false` |
| `toSorted()`, `toReversed()`, `toSpliced()` | нові масиви (ES2023) — незмінювальні аналоги |
| `with(index, value)` | новий масив із заміненим елементом (ES2023) |

```js
const nums = [10, 20, 30, 40];
nums.slice(1, 3);       // [20, 30]
nums.slice(-2);         // [30, 40]
nums.includes(20);      // true
nums.indexOf(99);       // -1
nums.join(' | ');       // '10 | 20 | 30 | 40'
nums.toReversed();      // [40, 30, 20, 10]; nums не змінився
```

:::caution[Мутація — часте джерело помилок]
Якщо функція отримує масив і викликає на ньому `sort()` чи `splice()`, вона змінює масив **у викликаючого коду**. Коли потрібен змінений варіант, а оригінал має залишитися — працюйте з копією (`[...arr].sort()`) або використовуйте `toSorted()`.
:::

## 8. Методи перебору і перетворення

Ці методи приймають **колбек** (лекція 4), який викликається для кожного елемента з аргументами `(element, index, array)`. Зазвичай потрібен лише перший.

### forEach — просто перебрати

```js
const prices = [120, 45, 300];
prices.forEach((price, i) => {
  console.log(`${i + 1}. ${price} грн`);
});
```

`forEach` нічого не повертає (`undefined`) і не підтримує `break`. Якщо потрібно зупинитися — `for...of` або `some`/`find`.

### map — перетворити кожен елемент

Повертає **новий масив тієї ж довжини**:

```js
const withVat = prices.map((p) => p * 1.2);        // [144, 54, 360]
const labels = prices.map((p) => `${p} грн`);      // ['120 грн', '45 грн', '300 грн']
const titles = expenses.map((e) => e.title);       // масив назв
```

### filter — відібрати елементи

Повертає **новий масив** з елементами, для яких колбек повернув truthy:

```js
const expensive = prices.filter((p) => p > 100);   // [120, 300]
const food = expenses.filter((e) => e.category === 'Їжа');
const withoutId3 = expenses.filter((e) => e.id !== 3); // «видалення» без мутації
```

### find, findIndex, findLast

```js
const item = expenses.find((e) => e.id === 3);        // перший знайдений об'єкт або undefined
const index = expenses.findIndex((e) => e.id === 3);  // його індекс або -1
const lastFood = expenses.findLast((e) => e.category === 'Їжа');
```

### some і every

```js
prices.some((p) => p > 250);    // true — хоча б один
prices.every((p) => p > 0);     // true — усі
[].every((p) => p > 1000);      // true (!) — для порожнього масиву every завжди true
```

### reduce — згорнути в одне значення

`reduce` проходить масив і накопичує результат. Колбек отримує **акумулятор** (накопичене значення) і поточний елемент; другий аргумент `reduce` — початкове значення акумулятора.

```js
const total = prices.reduce((sum, price) => sum + price, 0); // 465
```

Покроково:

| Крок | `sum` (до) | `price` | Повертає |
|---|---|---|---|
| 1 | 0 (початкове) | 120 | 120 |
| 2 | 120 | 45 | 165 |
| 3 | 165 | 300 | 465 |

`reduce` може будувати будь-що — наприклад, об'єкт з групуванням:

```js
const words = ['кіт', 'кит', 'дім', 'кіт', 'дім', 'кіт'];
const counts = words.reduce((acc, word) => {
  acc[word] = (acc[word] ?? 0) + 1;
  return acc;
}, {});
// { кіт: 3, кит: 1, дім: 2 }
```

:::tip[Завжди передавайте початкове значення]
Без другого аргументу `reduce` бере першим акумулятором перший елемент масиву, а на порожньому масиві кидає `TypeError: Reduce of empty array with no initial value`.
:::

### Ланцюжки методів

Оскільки `map` і `filter` повертають масиви, виклики можна об'єднувати:

```js
const foodTotal = expenses
  .filter((e) => e.category === 'Їжа')
  .map((e) => e.amount)
  .reduce((sum, a) => sum + a, 0);
```

### Порівняльна таблиця

| Метод | Повертає | Змінює масив | Типове використання |
|---|---|---|---|
| `forEach` | `undefined` | ні | побічні ефекти: вивести, додати в DOM |
| `map` | новий масив тієї ж довжини | ні | перетворити кожен елемент |
| `filter` | новий масив (≤ довжини) | ні | відібрати за умовою |
| `find` | елемент або `undefined` | ні | знайти один за умовою |
| `findIndex` | індекс або `-1` | ні | знайти позицію |
| `some` / `every` | boolean | ні | перевірити умову |
| `reduce` | будь-яке значення | ні | сума, групування, підрахунок |
| `sort` | той самий масив | **так** | сортування |

## 9. Сортування

`sort()` без аргументів сортує елементи **як рядки**:

```js
[10, 9, 1, 100].sort();       // [1, 10, 100, 9] — рядкове порівняння!
```

Для чисел потрібна **функція порівняння** (comparator) `(a, b) => число`:

- від'ємне — `a` перед `b`;
- додатне — `b` перед `a`;
- `0` — порядок не змінюється.

```js
const nums = [10, 9, 1, 100];
nums.sort((a, b) => a - b);   // за зростанням: [1, 9, 10, 100]
nums.sort((a, b) => b - a);   // за спаданням: [100, 10, 9, 1]

// Рядки з урахуванням української абетки
const names = ['Ярина', 'Іван', 'Євген', 'Андрій'];
names.sort((a, b) => a.localeCompare(b, 'uk')); // ['Андрій', 'Євген', 'Іван', 'Ярина']

// Масив об'єктів за полем
const byAmount = [...expenses].sort((a, b) => a.amount - b.amount);
// Дати у форматі YYYY-MM-DD можна порівнювати як рядки
const byDate = expenses.toSorted((a, b) => b.date.localeCompare(a.date)); // новіші першими
```

Зверніть увагу: `[...expenses].sort()` і `toSorted()` не змінюють вихідний масив `expenses`.

## 10. Масиви об'єктів: практичні шаблони

Типові дані вебзастосунку — масив однотипних об'єктів (з бази даних, API, форми). Візьмемо дані, з якими працюватимемо в наскрізному проєкті «Трекер витрат»:

```js
const expenses = [
  { id: 1, title: 'Обід у їдальні', amount: 95, category: 'Їжа', date: '2026-03-02' },
  { id: 2, title: 'Проїзний на місяць', amount: 480, category: 'Транспорт', date: '2026-03-01' },
  { id: 3, title: 'Кіно з друзями', amount: 220, category: 'Розваги', date: '2026-03-04' },
  { id: 4, title: 'Продукти на тиждень', amount: 860.5, category: 'Їжа', date: '2026-03-06' },
];
```

| Задача | Рішення |
|---|---|
| Загальна сума | `expenses.reduce((s, e) => s + e.amount, 0)` |
| Лише «Їжа» | `expenses.filter((e) => e.category === 'Їжа')` |
| Знайти за id | `expenses.find((e) => e.id === id)` |
| Список назв | `expenses.map((e) => e.title)` |
| Чи є витрати понад 500 | `expenses.some((e) => e.amount > 500)` |
| Найбільша витрата | `expenses.reduce((max, e) => (e.amount > max.amount ? e : max))` (непорожній масив) |
| Додати | `expenses.push(newExpense)` або `[...expenses, newExpense]` |
| Видалити за id | `expenses.filter((e) => e.id !== id)` |
| Оновити за id | `expenses.map((e) => (e.id === id ? { ...e, amount: 100 } : e))` |
| Унікальні категорії | `[...new Set(expenses.map((e) => e.category))]` |

### Групування: сума за категоріями

```js
function getStats(items) {
  return items.reduce((acc, { category, amount }) => {
    acc[category] = (acc[category] ?? 0) + amount;
    return acc;
  }, {});
}

getStats(expenses);
// { 'Їжа': 955.5, 'Транспорт': 480, 'Розваги': 220 }
```

У сучасних браузерах для цього також є `Object.groupBy(items, (e) => e.category)` (ES2024) — він групує самі об'єкти в масиви за ключем.

### Виведення таблицею

`console.table(expenses)` показує масив об'єктів у консолі як таблицю — дуже зручно для налагодження.

### Короткий погляд на Set і Map

| Структура | Що це | Коли використовувати |
|---|---|---|
| `Set` | набір унікальних значень | прибрати дублікати, швидко перевіряти «чи є» (`set.has(x)`) |
| `Map` | словник з ключами будь-якого типу, зберігає порядок | ключі-об'єкти, часті додавання/видалення |

```js
const unique = new Set(['Їжа', 'Їжа', 'Інше']); // Set(2) {'Їжа', 'Інше'}
unique.has('Їжа');                               // true

const prices = new Map([['кава', 60], ['чай', 40]]);
prices.get('кава');                              // 60
```

### Типові помилки

| Помилка | Приклад | Виправлення |
|---|---|---|
| Очікування копії при присвоєнні | `const b = a; b.push(1)` змінює `a` | `[...a]`, `{ ...a }`, `structuredClone` |
| `sort()` без компаратора для чисел | `[10, 9, 1].sort()` | `sort((a, b) => a - b)` |
| Забули `return` у колбеку з `{}` | `arr.map((x) => { x * 2 })` → `[undefined, ...]` | `arr.map((x) => x * 2)` |
| `reduce` без початкового значення | помилка на порожньому масиві | `reduce(fn, 0)` |
| `forEach` з очікуванням результату | `const r = arr.forEach(...)` → `undefined` | `map` / `filter` |
| Порівняння масивів/об'єктів через `===` | `[1] === [1]` → `false` | порівнювати вміст |
| `obj.key` замість `obj[key]` для змінної | `stats.category` | `stats[category]` |
| Мутація під час перебору | `splice` у `forEach` | `filter` у новий масив |

## Підсумки

- Об'єкт — набір властивостей «ключ: значення». Доступ — через крапку або `[ ]` (для обчислюваних ключів). Безпечний доступ — `?.`, перевірка наявності — `in` / `Object.hasOwn`.
- Метод — властивість-функція; `this` — об'єкт перед крапкою під час виклику. Стрілкові функції не використовують як методи.
- `Object.keys/values/entries` перетворюють об'єкт на масиви для перебору.
- Змінні з об'єктами зберігають посилання. Spread дає поверхневу копію, `structuredClone` — глибоку. Краще створювати нові об'єкти, ніж змінювати наявні.
- Деструктуризація розпаковує властивості та елементи в змінні; spread розгортає, rest збирає.
- Масиви: `push/pop/shift/unshift/splice/sort` змінюють масив; `slice/concat/map/filter/toSorted` — повертають нові.
- `map` — перетворення, `filter` — відбір, `find` — пошук, `some/every` — перевірка, `reduce` — згортання. Ланцюжки методів — основний інструмент обробки даних.
