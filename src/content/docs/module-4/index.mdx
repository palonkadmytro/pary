Модуль знайомить із серверною розробкою на **PHP 8**. Ми обробляємо форми, працюємо з базою даних MySQL, реалізуємо автентифікацію через сесії, пишемо простий REST API та викладаємо проєкт на хостинг.

| | Години | Пари |
| --- | --- | --- |
| Лекції | 10 | 5 |
| Практичні | 18 | 9 |
| **Разом** | **28** | **14** |

:::tip[Наскрізний проєкт «Міні-блог»]
Починаючи з практичної про форми, ми будуємо блог.
Спершу пости зберігаються у JSON-файлі, потім додаємо валідацію та захист від XSS і CSRF.
Далі переходимо на MySQL і PDO, додаємо коментарі, реєстрацію та вхід, а наостанок пишемо REST API і розгортаємо блог на хостингу.
:::

Після кожної пари є невелике **домашнє завдання**.
