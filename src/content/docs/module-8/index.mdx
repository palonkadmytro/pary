Модуль присвячено розробці кросплатформних мобільних застосунків для Android та iOS на **React Native** з використанням **Expo**.
Від знайомства з платформою до збірки готового застосунку та публікації в Google Play.

| | Години | Пари |
| --- | --- | --- |
| Лекції | 14 | 7 |
| Практичні | 16 | 8 |
| **Разом** | **30** | **15** |

:::tip[Наскрізний проєкт «Мої місця»]
На всіх практичних ми поступово будуємо один застосунок — щоденник місць, які ти відвідав:
список і картки місць → стан та стилі → погода з API і збереження даних → навігація між екранами → карта, геолокація та камера → оптимізація, збірка APK і публікація.
Кожна практична починається з результату попередньої, тому не пропускай їх.
:::

Після кожної пари є невелике **домашнє завдання**.
