## Мета заняття

- Зрозуміти, як програма приймає рішення: інструкції `if`, `else if`, `else`.
- Навчитися будувати складні умови з логічних операторів і пам'ятати про truthy/falsy.
- Розрізняти інструкції та вирази; знати, коли доречний тернарний оператор, а коли — `if`.
- Опанувати `switch` і його особливості (строге порівняння, «провалювання», `break`).
- Вивчити всі види циклів JavaScript і вміти обрати потрібний: `for`, `while`, `do...while`, `for...of`, `for...in`.
- Керувати виконанням циклу через `break`, `continue` і мітки.
- Розпізнавати та уникати типових помилок: нескінченні цикли, помилки «на одиницю», зміна колекції під час обходу.

## 1. Умовна інструкція if

Програма рідко виконується строго «згори донизу». Потрібно реагувати на дані: якщо сума покупки більше 1000 грн — дати знижку, якщо поле порожнє — показати помилку. Для цього є **умовні конструкції** (conditional statements).

### Блок

**Блок** — група інструкцій у фігурних дужках `{ }`. Він утворює власну область видимості для `let` і `const`.

```js
{
  const message = 'Я всередині блоку';
  console.log(message);
}
// message тут не існує
```

### if, else, else if

```js
const amount = 1250;

if (amount > 1000) {
  console.log('Знижка 5 %');
}
```

Вираз у дужках обчислюється і **перетворюється на boolean**. Якщо `true` — виконується блок.

Гілка `else` виконується, коли умова хибна:

```js
const temperature = 12;

if (temperature >= 18) {
  console.log('Можна без куртки');
} else {
  console.log('Вдягніть куртку');
}
```

Ланцюжок `else if` перевіряє кілька умов **по черзі**; спрацьовує **перша** істинна гілка, решта пропускається:

```js
const score = 83;
let grade;

if (score >= 90) {
  grade = 'A';
} else if (score >= 82) {
  grade = 'B';
} else if (score >= 74) {
  grade = 'C';
} else if (score >= 64) {
  grade = 'D';
} else if (score >= 60) {
  grade = 'E';
} else {
  grade = 'F';
}

console.log(grade); // 'B'
```

Порядок гілок важливий: якби першою стояла умова `score >= 60`, будь-яка оцінка від 60 отримала б «E».

:::caution[Фігурні дужки — завжди]
Синтаксис дозволяє не писати `{ }`, якщо в гілці одна інструкція:

```js
if (isAdmin) showPanel();
```

Але при додаванні другого рядка легко отримати помилку:

```js
if (isAdmin)
  showPanel();
  deleteAll();   // виконується ЗАВЖДИ — відступ нічого не означає!
```

У курсі завжди ставимо фігурні дужки.
:::

### Умова з truthy/falsy

Оскільки умова перетворюється на boolean, можна писати коротко:

```js
const name = input.trim();

if (name) {               // те саме, що name !== ''
  console.log(`Привіт, ${name}`);
}

if (!items.length) {      // масив порожній
  console.log('Список порожній');
}
```

Але обережно з числами: `if (count)` хибне і для `0`, що часто є коректним значенням. Тоді пишіть явно: `if (count !== undefined)` або `if (count > 0)`.

## 2. Складні умови

Умови комбінують логічними операторами `&&` (і), `||` (або), `!` (не):

```js
const age = 20;
const hasTicket = true;
const isVip = false;

if (age >= 18 && hasTicket) {
  console.log('Вхід дозволено');
}

if (isVip || age < 6) {
  console.log('Безкоштовно');
}

if (!(age >= 18)) {      // те саме, що age < 18
  console.log('Лише з батьками');
}
```

Діапазони записують двома порівняннями — математичний запис `18 <= age <= 60` у JS **не працює так, як очікується**:

```js
const age = 75;
console.log(18 <= age <= 60); // true (!) — (18 <= 75) → true → true <= 60 → 1 <= 60
console.log(age >= 18 && age <= 60); // false — правильно
```

### Закони де Моргана

Заперечення складної умови спрощують за законами де Моргана:

| Вираз | Еквівалент |
|---|---|
| `!(a && b)` | `!a \|\| !b` |
| `!(a \|\| b)` | `!a && !b` |

```js
// «Не (вихідний і гарна погода)»
if (!(isWeekend && isSunny)) { /* ... */ }
// те саме, але читається легше:
if (!isWeekend || !isSunny) { /* ... */ }
```

### Іменовані умови

Складну умову краще винести у змінну з промовистою назвою:

```js
// Погано: що тут перевіряється?
if (user.age >= 18 && user.balance >= price && !user.isBlocked) { /* ... */ }

// Добре
const isAdult = user.age >= 18;
const canAfford = user.balance >= price;
const canBuy = isAdult && canAfford && !user.isBlocked;

if (canBuy) { /* ... */ }
```

### Ранній вихід (guard clause)

Глибока вкладеність `if` у `if` — ознака коду, який важко читати («піраміда приреченості»). Прийом **раннього виходу** (guard clause) перевіряє помилкові випадки першими і одразу завершує функцію:

```js
// Погано: вкладеність
function checkout(cart, user) {
  if (user) {
    if (cart.length > 0) {
      if (user.balance >= total(cart)) {
        pay(cart, user);
      }
    }
  }
}

// Добре: ранній вихід
function checkout(cart, user) {
  if (!user) return;
  if (cart.length === 0) return;
  if (user.balance < total(cart)) return;

  pay(cart, user);
}
```

Функції ми детально розберемо на лекції 4, але прийом варто запам'ятати вже зараз.

## 3. Тернарний оператор і логічні оператори

### Інструкція чи вираз

**Інструкція** (statement) виконує дію, **вираз** (expression) обчислюється у значення. `if` — інструкція: її не можна присвоїти змінній чи вставити в шаблонний рядок. Тернарний оператор — вираз:

```js
const balance = -50;
const status = balance >= 0 ? 'в плюсі' : 'борг';
console.log(`Рахунок: ${status}`);
console.log(`У кошику ${n} ${n === 1 ? 'товар' : 'товари'}`);
```

| Ситуація | Що обрати |
|---|---|
| Вибрати одне з двох значень | тернарний оператор |
| Виконати різні дії (кілька інструкцій) | `if...else` |
| Три і більше варіантів | `if...else if` або `switch` |
| Вкладений тернарний оператор | майже завжди краще переписати на `if` |

### && і || як короткі розгалуження

Завдяки короткій схемі обчислення:

```js
// Виконати дію, лише якщо умова істинна
isLoggedIn && showProfile();

// Значення за замовчуванням
const title = userTitle || 'Без назви';
const limit = settings.limit ?? 100;
```

Перший прийом популярний у React (JSX), але у звичайному коді `if (isLoggedIn) showProfile();` зрозуміліший.

## 4. Інструкція switch

`switch` порівнює одне значення з кількома варіантами. Зручний, коли гілок багато і всі перевіряють **рівність** одного виразу.

```js
const day = 3;
let dayName;

switch (day) {
  case 1:
    dayName = 'Понеділок';
    break;
  case 2:
    dayName = 'Вівторок';
    break;
  case 3:
    dayName = 'Середа';
    break;
  case 4:
    dayName = 'Четвер';
    break;
  case 5:
    dayName = 'П\'ятниця';
    break;
  case 6:
  case 7:                 // кілька case для однієї гілки
    dayName = 'Вихідний';
    break;
  default:                // якщо жоден case не підійшов
    dayName = 'Невідомий день';
}
```

Особливості `switch`:

1. Порівняння **строге** (`===`): `case '3'` не спрацює для числа `3`.
2. Після збігу виконання **«провалюється» (fall-through)** далі — у наступні `case`, поки не зустріне `break`. Це дозволяє групувати варіанти (як 6 і 7 вище), але забутий `break` — класична помилка.
3. `default` необов'язковий, але бажаний — він обробляє несподівані значення.

```js
// Помилка: забули break
const role = 'editor';
switch (role) {
  case 'admin':
    console.log('Може все');
  case 'editor':
    console.log('Може редагувати');   // виконається
  case 'viewer':
    console.log('Може переглядати');  // теж виконається — провалювання!
}
```

:::tip[Альтернатива switch — об'єкт-довідник]
Якщо `switch` просто зіставляє значення зі значенням, зручніше використати об'єкт:

```js
const dayNames = {
  1: 'Понеділок', 2: 'Вівторок', 3: 'Середа',
  4: 'Четвер', 5: 'П\'ятниця', 6: 'Субота', 7: 'Неділя',
};
const dayName = dayNames[day] ?? 'Невідомий день';
```

Детально про об'єкти — на лекції 6.
:::

Для діапазонів `switch` не підходить (хіба що прийом `switch (true)`, який вважається незвичним). Діапазони — це `if...else if`.

## 5. Цикли while і do...while

**Цикл** (loop) повторює блок коду, доки виконується умова. Кожне виконання тіла циклу називають **ітерацією**.

### while

```js
let count = 3;

while (count > 0) {
  console.log(`Залишилось: ${count}`);
  count--;           // без цього рядка цикл нескінченний!
}
console.log('Старт!');
```

Умова перевіряється **перед** кожною ітерацією. Якщо вона хибна від початку, тіло не виконається жодного разу.

`while` зручний, коли **кількість повторень невідома заздалегідь**:

```js
// Скільки років потрібно, щоб вклад подвоївся під 12 % річних?
let deposit = 10_000;
let years = 0;

while (deposit < 20_000) {
  deposit *= 1.12;
  years++;
}

console.log(`Знадобиться ${years} років`); // 7
```

### do...while

Умова перевіряється **після** ітерації, тому тіло виконується **хоча б один раз**:

```js
let input;

do {
  input = prompt('Введіть число від 1 до 10');
} while (input !== null && (Number(input) < 1 || Number(input) > 10));
```

На практиці `do...while` трапляється рідко — коли дію точно треба виконати перед першою перевіркою.

## 6. Цикл for

Найуживаніший цикл, коли відома кількість повторень або потрібен лічильник:

```js
for (let i = 0; i < 5; i++) {
  console.log(i); // 0, 1, 2, 3, 4
}
```

Заголовок складається з трьох частин, розділених `;`:

| Частина | Приклад | Коли виконується |
|---|---|---|
| Ініціалізація | `let i = 0` | один раз перед циклом |
| Умова | `i < 5` | перед кожною ітерацією |
| Крок | `i++` | після кожної ітерації |

Порядок виконання: ініціалізація → умова → тіло → крок → умова → тіло → крок → … → умова хибна → вихід.

Змінна `i`, оголошена через `let`, існує лише всередині циклу, причому на кожній ітерації — **власна копія** (це важливо для замикань, лекція 4).

Різні варіації:

```js
// Зворотний відлік
for (let i = 10; i > 0; i--) { /* 10..1 */ }

// Крок 2: парні числа
for (let i = 0; i <= 20; i += 2) { /* 0, 2, ..., 20 */ }

// Обхід масиву за індексом
const marks = [90, 75, 82];
for (let i = 0; i < marks.length; i++) {
  console.log(`Оцінка №${i + 1}: ${marks[i]}`);
}

// Будь-яку частину можна пропустити (крапки з комою обов'язкові)
let j = 0;
for (; j < 3; ) {
  j++;
}
```

### Вкладені цикли

Цикл усередині циклу — для таблиць, матриць, перебору пар:

```js
// Таблиця множення 1..3
for (let row = 1; row <= 3; row++) {
  let line = '';
  for (let col = 1; col <= 3; col++) {
    line += `${row * col}\t`;
  }
  console.log(line);
}
// 1  2  3
// 2  4  6
// 3  6  9
```

Кількість ітерацій вкладених циклів множиться: 1000 × 1000 = мільйон. Це варто пам'ятати, коли даних багато.

## 7. Цикли for...of і for...in

### for...of — значення колекції

Перебирає **значення** будь-якого ітерованого (iterable) об'єкта: масиву, рядка, `Set`, `Map`, колекції DOM-елементів.

```js
const fruits = ['яблуко', 'груша', 'слива'];

for (const fruit of fruits) {
  console.log(fruit);
}

for (const char of 'Київ') {
  console.log(char); // К, и, ї, в
}
```

Коли не потрібен індекс, `for...of` читабельніший і безпечніший за класичний `for`: немає лічильника, немає ризику помилитися з межею. Змінну можна оголошувати через `const`, бо на кожній ітерації вона нова.

Якщо індекс усе ж потрібен — метод `entries()`:

```js
for (const [index, fruit] of fruits.entries()) {
  console.log(`${index + 1}. ${fruit}`);
}
```

### for...in — ключі об'єкта

Перебирає **імена властивостей** (ключі) об'єкта:

```js
const student = { name: 'Олена', course: 2, group: 'ІПЗ-21' };

for (const key in student) {
  console.log(`${key}: ${student[key]}`);
}
// name: Олена
// course: 2
// group: ІПЗ-21
```

:::caution[for...in не для масивів]
`for...in` над масивом поверне індекси **рядками** (`'0'`, `'1'`…), може захопити успадковані властивості й не гарантує порядок у всіх випадках. Для масивів — `for...of`, `for` або методи масивів (`forEach`, `map`…).
:::

### Порівняння циклів

| Цикл | Що перебирає | Коли використовувати |
|---|---|---|
| `for` | лічильник | потрібен індекс, крок ≠ 1, зворотний порядок |
| `while` | поки умова істинна | кількість ітерацій невідома |
| `do...while` | поки умова істинна, мінімум 1 раз | дія перед першою перевіркою |
| `for...of` | значення iterable | масиви, рядки, колекції DOM |
| `for...in` | ключі об'єкта | властивості звичайного об'єкта |
| `arr.forEach()` | елементи масиву | функціональний стиль (лекція 6) |

## 8. break, continue і мітки

`break` **повністю завершує** цикл:

```js
const numbers = [4, 9, -2, 7, 5];
let firstNegative = null;

for (const n of numbers) {
  if (n < 0) {
    firstNegative = n;
    break;               // далі шукати немає сенсу
  }
}
console.log(firstNegative); // -2
```

`continue` **пропускає залишок поточної ітерації** і переходить до наступної:

```js
// Сума лише додатних
let sum = 0;
for (const n of numbers) {
  if (n <= 0) continue;
  sum += n;
}
console.log(sum); // 25
```

`break` і `continue` впливають лише на **найближчий** цикл. Щоб вийти із зовнішнього циклу, використовують **мітку** (label):

```js
const matrix = [
  [1, 2, 3],
  [4, 0, 6],
  [7, 8, 9],
];

search: for (const row of matrix) {
  for (const value of row) {
    if (value === 0) {
      console.log('Знайдено нуль');
      break search;       // вихід з обох циклів
    }
  }
}
```

Мітки трапляються рідко; часто зручніше винести вкладені цикли у функцію і використати `return`.

## 9. Типові алгоритми та помилки

### Шаблони, які варто знати напам'ять

```js
const prices = [120, 45, 300, 80, 15];

// 1. Накопичення суми
let total = 0;
for (const p of prices) {
  total += p;
}

// 2. Пошук максимуму
let max = prices[0];
for (const p of prices) {
  if (p > max) max = p;
}

// 3. Підрахунок за умовою
let cheap = 0;
for (const p of prices) {
  if (p < 100) cheap++;
}

// 4. Побудова рядка
let report = '';
for (let i = 0; i < prices.length; i++) {
  report += `${i + 1}) ${prices[i]} грн\n`;
}

// 5. Перевірка «чи є хоч один» з прапорцем
let hasExpensive = false;
for (const p of prices) {
  if (p > 250) {
    hasExpensive = true;
    break;
  }
}
```

Більшість із цих задач на лекції 6 розв'яжемо коротше — методами масивів `reduce`, `filter`, `some`. Але розуміння циклів — фундамент.

### FizzBuzz

Класична задача: вивести числа від 1 до 15, замінюючи кратні 3 на «Fizz», кратні 5 — на «Buzz», кратні обом — на «FizzBuzz».

```js
for (let i = 1; i <= 15; i++) {
  if (i % 15 === 0) {
    console.log('FizzBuzz');   // перевіряємо найсуворішу умову першою
  } else if (i % 3 === 0) {
    console.log('Fizz');
  } else if (i % 5 === 0) {
    console.log('Buzz');
  } else {
    console.log(i);
  }
}
```

### Типові помилки

| Помилка | Приклад | Наслідок / виправлення |
|---|---|---|
| Нескінченний цикл | `while (i < 10) { console.log(i); }` — забули `i++` | вкладка «зависає»; закрийте її і змініть код |
| Помилка на одиницю (off-by-one) | `for (let i = 0; i <= arr.length; i++)` | остання ітерація звертається до `arr[arr.length]` → `undefined`; правильно `<` |
| Крапка з комою після заголовка | `for (let i = 0; i < 3; i++);` | порожнє тіло, блок нижче виконується один раз |
| `=` в умові | `if (x = 0)` | присвоєння, умова завжди хибна; пишіть `===` |
| Порівняння дробових лічильників | `for (let x = 0; x !== 1; x += 0.1)` | через неточність ніколи не рівно 1 → нескінченний цикл; використовуйте `<` |
| Зміна масиву під час обходу | видалення елементів у `for` вперед | пропуск елементів; обходьте з кінця або створюйте новий масив |
| `for...in` для масиву | індекси-рядки | використовуйте `for...of` |

:::tip[Як «врятувати» вкладку з нескінченним циклом]
У Chrome відкрийте диспетчер завдань браузера (`Shift+Esc`) і завершіть процес вкладки. Live Server перезапустить сторінку після збереження виправленого файлу. Під час налагодження корисна «страховка» — лічильник ітерацій з `break`, якщо він перевищив, наприклад, 10 000.
:::

### Налагодження циклів у DevTools

1. Відкрийте вкладку **Sources**, знайдіть свій `script.js`.
2. Клацніть номер рядка всередині циклу — з'явиться **точка зупинки** (breakpoint).
3. Перезавантажте сторінку: виконання зупиниться, у панелі **Scope** видно значення змінних.
4. Кнопка **Resume** (`F8`) — до наступної зупинки (наступна ітерація), **Step over** (`F10`) — на один рядок.

Також можна написати в коді інструкцію `debugger;` — вона діє як точка зупинки, коли DevTools відкриті.

## Підсумки

- `if...else if...else` виконує першу гілку з істинною умовою; умова перетворюється на boolean за правилами truthy/falsy. Фігурні дужки — завжди.
- Складні умови будуємо з `&&`, `||`, `!`, виносимо в іменовані змінні, використовуємо ранній вихід замість вкладеності.
- Тернарний оператор — вираз для вибору одного з двох значень; `if` — для дій.
- `switch` порівнює строго, «провалюється» без `break`; часто його замінює об'єкт-довідник.
- Цикли: `for` — з лічильником, `while` — до виконання умови, `do...while` — щонайменше раз, `for...of` — значення колекцій, `for...in` — ключі об'єктів.
- `break` завершує цикл, `continue` — поточну ітерацію; мітки дозволяють вийти з кількох циклів.
- Найчастіші помилки: нескінченний цикл, помилка на одиницю, `=` замість `===`.

## Контрольні питання

1. У якому порядку перевіряються гілки `else if`? Чому порядок важливий?
2. Чому вираз `18 <= age <= 60` не перевіряє діапазон? Як записати правильно?
3. Що таке ранній вихід (guard clause) і яку проблему він розв'язує?
4. Чим інструкція відрізняється від виразу? Наведіть приклад, де тернарний оператор можна використати, а `if` — ні.
5. Що таке «провалювання» у `switch`? Коли воно корисне, а коли шкідливе?
6. Яким способом `switch` порівнює значення?
7. Чим `while` відрізняється від `do...while`?
8. Опишіть порядок виконання частин заголовка циклу `for`.
9. Чим `for...of` відрізняється від `for...in`? Чому `for...in` не рекомендують для масивів?
10. Що роблять `break` і `continue`? Як вийти з двох вкладених циклів одночасно?
