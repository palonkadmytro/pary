## 1. JavaScript у браузері

**JavaScript (JS)** — динамічна мова програмування, яку виконує кожен сучасний браузер. Якщо HTML відповідає за **структуру** сторінки, CSS — за **вигляд**, то JavaScript — за **поведінку**: реакцію на дії користувача, зміну вмісту без перезавантаження, завантаження даних із сервера, перевірку форм тощо.

| Технологія | Відповідає за | Приклад |
|---|---|---|
| HTML | структуру і зміст | заголовок, форма, список |
| CSS | зовнішній вигляд | кольори, відступи, сітка |
| JavaScript | поведінку і логіку | підрахунок суми, додавання елемента до списку |

Мова стандартизована під назвою **ECMAScript** (специфікація ECMA-262). З 2015 року (ES2015, або ES6) нова версія стандарту виходить щороку: ES2016, ES2017, …, ES2025. У курсі ми пишемо сучасний JavaScript (ES2022+), який підтримують усі актуальні браузери.

:::note
JavaScript і Java — **різні мови**, схожість назв — маркетинговий хід 1995 року. JavaScript виконується не лише в браузері: середовище **Node.js** дозволяє запускати його на сервері чи в терміналі. Але в цьому модулі нас цікавить саме браузер.
:::

### Як браузер виконує JS

У кожному браузері є **рушій JavaScript** (JavaScript engine): V8 у Chrome і Edge, SpiderMonkey у Firefox, JavaScriptCore у Safari. Рушій отримує текст програми, розбирає (парсить) його, компілює «на льоту» (JIT, just-in-time) у машинний код і виконує.

Крім самої мови, браузер надає скриптам **Web API** — набір об'єктів для роботи зі сторінкою та середовищем: `document` (DOM), `console`, `fetch`, `localStorage`, `setTimeout` тощо. Сама мова JavaScript нічого «не знає» про сторінки — усе це можливості браузера.

### Підключення скрипта

Скрипт підключається тегом `<script>`. Є два способи: вбудований код (inline) і зовнішній файл.

```html title="index.html"
<!-- 1. Вбудований скрипт: код прямо в HTML (лише для маленьких прикладів) -->
<script>
  console.log('Привіт із вбудованого скрипта');
</script>

<!-- 2. Зовнішній файл: рекомендований спосіб -->
<script src="script.js"></script>
```

Зовнішній файл кращий: код відокремлений від розмітки, браузер кешує файл, його зручно редагувати й перевикористовувати.

Важливе питання — **де** розміщувати `<script>`. Браузер читає HTML зверху вниз. Коли він зустрічає звичайний `<script src>`, то **зупиняє розбір сторінки**, завантажує і виконує скрипт, і лише потім продовжує. Якщо скрипт у `<head>` звертається до елементів сторінки, їх ще не існує.

| Варіант | Коли виконується | Чи доступні елементи сторінки | Коментар |
|---|---|---|---|
| `<script src>` у `<head>` | одразу, блокує розбір | ні | застарілий підхід |
| `<script src>` перед `</body>` | після розбору всієї розмітки над ним | так | класичний підхід |
| `<script src defer>` у `<head>` | після повного розбору HTML, у порядку підключення | так | **рекомендований** |
| `<script src async>` | одразу після завантаження, порядок не гарантований | не гарантовано | для незалежних скриптів (аналітика) |
| `<script type="module" src>` | як `defer` + режим модулів | так | для коду з `import`/`export` |

```html title="index.html"
<!doctype html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <title>Перший скрипт</title>
  <!-- defer: файл завантажується паралельно, виконується після розбору HTML -->
  <script src="script.js" defer></script>
</head>
<body>
  <h1>Привіт, JavaScript!</h1>
</body>
</html>
```

:::tip[Правило курсу]
У всіх практичних ми підключаємо скрипт у `<head>` з атрибутом `defer`. Так скрипт не блокує показ сторінки і гарантовано бачить усю розмітку.
:::

## 2. Базовий синтаксис

### Інструкції і крапка з комою

Програма складається з **інструкцій** (statements) — команд, які виконуються по черзі. Інструкції розділяють крапкою з комою `;`.

```js
let price = 120;
let count = 3;
console.log(price * count);
```

JavaScript має механізм **автоматичної вставки крапки з комою** (ASI, Automatic Semicolon Insertion): якщо крапку з комою пропущено в кінці рядка, рушій часто «вставить» її сам. Але не завжди так, як ви очікуєте:

```js
// Очікуємо повернути об'єкт, а отримаємо undefined!
function getUser() {
  return       // ASI вставляє ; одразу після return
  {
    name: 'Олена'
  };
}
```

:::caution[Домовленість]
У курсі ми **завжди ставимо крапку з комою** в кінці інструкцій і не переносимо значення після `return` на новий рядок. Автоформатувальник Prettier зробить це за вас.
:::

### Коментарі

```js
// Однорядковий коментар

/*
  Багаторядковий коментар.
  Використовують для довших пояснень.
*/

/**
 * Документувальний коментар (JSDoc) перед функцією.
 * @param {number} a
 */
```

Коментуйте **чому** зроблено саме так, а не **що** робить очевидний рядок коду.

### Регістр і ідентифікатори

JavaScript **чутливий до регістру**: `price`, `Price` і `PRICE` — три різні змінні.

**Ідентифікатор** (ім'я змінної, функції) може містити літери, цифри, `_` і `$`, але не може починатися з цифри і не може збігатися із зарезервованим словом (`let`, `class`, `return`, `if`…).

| Ім'я | Допустиме? | Коментар |
|---|---|---|
| `totalPrice` | так | camelCase — стандарт для змінних і функцій |
| `_count`, `$el` | так | `_` і `$` дозволені |
| `MAX_SIZE` | так | UPPER_SNAKE_CASE — для констант-налаштувань |
| `2items` | ні | починається з цифри |
| `user-name` | ні | дефіс — це оператор віднімання |
| `class` | ні | зарезервоване слово |
| `ціна` | технічно так | але використовуйте лише англійські імена |

### Консоль розробника

Головний інструмент для перших кроків — **консоль** у DevTools (`F12` або `Ctrl+Shift+J` / `Cmd+Option+J` у Chrome). У ній видно повідомлення скриптів і помилки, а також можна виконувати JS-вирази.

```js
console.log('Звичайне повідомлення', 42, true);
console.info('Інформація');
console.warn('Попередження');      // жовте
console.error('Помилка');          // червоне
console.table([{ a: 1 }, { a: 2 }]); // дані у вигляді таблиці
```

:::tip
У `console.log` можна передати кілька значень через кому — вони виведуться через пробіл, причому числа й рядки буде видно різними кольорами. Це зручно для налагодження: `console.log('price =', price)`.
:::

### Строгий режим

Директива `'use strict';` на початку файлу вмикає **строгий режим** (strict mode): частина «тихих» помилок стає явними (наприклад, присвоєння неоголошеній змінній). У модулях (`type="module"`) і класах строгий режим увімкнено автоматично. У звичайних скриптах курсу ми пишемо `'use strict';` першим рядком.

## 3. Змінні

**Змінна** (variable) — іменоване «сховище» для значення. Точніше: ім'я, яке посилається на значення в пам'яті.

### let і const

```js
let age = 19;        // змінна, значення можна змінювати
age = 20;            // повторне присвоєння — дозволено

const PI = 3.14159;  // константа: повторне присвоєння заборонене
PI = 3;              // TypeError: Assignment to constant variable.

let city;            // оголошення без значення → undefined
console.log(city);   // undefined
```

`const` обов'язково ініціалізується при оголошенні: `const x;` — синтаксична помилка.

:::caution[const не означає «незмінне значення»]
`const` забороняє **переприсвоїти змінну**, а не змінювати вміст об'єкта, на який вона посилається:

```js
const user = { name: 'Іван' };
user.name = 'Петро';   // можна: змінюємо вміст об'єкта
user = {};             // TypeError: змінну переприсвоїти не можна
```

Детально про посилання — на лекції про об'єкти та масиви.
:::

**Правило вибору:** за замовчуванням пишіть `const`. Якщо значення справді має змінюватися (лічильник, накопичувач суми) — `let`. Так код легше читати: одразу видно, що «рухається».

### Область видимості

`let` і `const` мають **блокову область видимості** (block scope): змінна існує лише всередині фігурних дужок `{ }`, де оголошена.

```js
const discount = 10;

if (discount > 0) {
  const message = 'Діє знижка';
  console.log(message);  // 'Діє знижка'
  console.log(discount); // 10 — зовнішня змінна видима всередині
}

console.log(message);    // ReferenceError: message is not defined
```

### Застарілий var

До ES2015 існував лише `var`. Він досі працює, але має неочевидну поведінку:

| Властивість | `var` | `let` | `const` |
|---|---|---|---|
| Область видимості | функція | блок | блок |
| Повторне оголошення | дозволене | помилка | помилка |
| Переприсвоєння | так | так | ні |
| Підняття (hoisting) | так, зі значенням `undefined` | так, але TDZ | так, але TDZ |
| Властивість `window` (глобально) | так | ні | ні |

```js
if (true) {
  var leaked = 'я «втік» з блоку';
}
console.log(leaked); // 'я «втік» з блоку' — var ігнорує блок

console.log(early);  // undefined — оголошення var «підняте» вгору
var early = 5;
```

### Підняття і тимчасова мертва зона

**Підняття** (hoisting) — рушій ще до виконання коду «знає» про всі оголошення в області видимості. Для `var` змінна одразу існує зі значенням `undefined`. Для `let`/`const` змінна теж зареєстрована, але до рядка оголошення перебуває у **тимчасовій мертвій зоні** (TDZ, Temporal Dead Zone) — будь-яке звернення дає помилку:

```js
console.log(total); // ReferenceError: Cannot access 'total' before initialization
let total = 100;
```

Це корисна поведінка: помилка вказує на баг одразу, а не «тихо» повертає `undefined`.

:::danger[Ніколи не створюйте змінні без оголошення]
```js
score = 10; // без let/const
```
У нестрогому режимі це створить **глобальну** змінну, у строгому — `ReferenceError`. Тому й потрібен `'use strict'`.
:::

## 4. Типи даних

JavaScript — мова з **динамічною типізацією**: тип має значення, а не змінна. Одна й та сама змінна може зберігати спочатку число, потім рядок (але робити так не варто).

```js
let value = 42;       // number
value = 'сорок два';  // тепер string
```

У мові **8 типів**: 7 примітивних (primitive) і об'єкти (object).

| Тип | Приклади | `typeof` |
|---|---|---|
| `number` | `42`, `3.14`, `-7`, `NaN`, `Infinity` | `'number'` |
| `bigint` | `9007199254740993n` | `'bigint'` |
| `string` | `'текст'`, `"текст"`, `` `шаблон` `` | `'string'` |
| `boolean` | `true`, `false` | `'boolean'` |
| `undefined` | `undefined` | `'undefined'` |
| `null` | `null` | `'object'` (історична помилка!) |
| `symbol` | `Symbol('id')` | `'symbol'` |
| `object` | `{}`, `[]`, `new Date()`, функції | `'object'` / `'function'` |

### Числа (number)

Усі звичайні числа в JS — 64-бітні числа з плаваючою крапкою (стандарт IEEE 754). Окремого типу «ціле число» немає.

```js
const price = 199.99;
const big = 1_000_000;      // підкреслення для читабельності (ES2021)
const hex = 0xff;           // 255
const tiny = 2.5e-3;        // 0.0025

console.log(10 / 0);        // Infinity
console.log('abc' * 2);     // NaN — Not a Number, «не число»
console.log(typeof NaN);    // 'number' — парадокс, але так
console.log(NaN === NaN);   // false! NaN не дорівнює навіть собі
console.log(Number.isNaN(NaN)); // true — правильна перевірка
```

**Проблема точності** — класика співбесід:

```js
console.log(0.1 + 0.2);            // 0.30000000000000004
console.log(0.1 + 0.2 === 0.3);    // false
console.log((0.1 + 0.2).toFixed(2)); // '0.30' — рядок!
```

Числа 0.1 і 0.2 неможливо точно записати у двійковій системі, як 1/3 — у десятковій. Для грошей це критично, тому розрахунки часто ведуть **у копійках** (цілими числами) або округлюють результат лише під час виведення.

Цілі числа безпечні лише до `Number.MAX_SAFE_INTEGER` (2⁵³ − 1 ≈ 9·10¹⁵). Для більших — тип `bigint` (суфікс `n`), який не можна змішувати зі звичайними числами в одному виразі.

Корисні можливості об'єкта `Math` і методів чисел:

```js
Math.round(4.5);     // 5
Math.floor(4.9);     // 4 — вниз
Math.ceil(4.1);      // 5 — вгору
Math.trunc(-4.9);    // -4 — відкинути дробову частину
Math.max(3, 8, 1);   // 8
Math.random();       // випадкове від 0 (включно) до 1 (не включно)
Math.abs(-5);        // 5
2 ** 10;             // 1024 — піднесення до степеня

(1234.567).toFixed(1);               // '1234.6'
(1234.5).toLocaleString('uk-UA');    // '1 234,5'
```

### Рядки (string)

Рядки записують в одинарних `'...'`, подвійних `"..."` лапках або в зворотних апострофах `` `...` `` — **шаблонних рядках** (template literals).

```js
const name = 'Олена';
const course = 2;

// Конкатенація (склеювання) оператором +
const s1 = 'Студентка ' + name + ', курс ' + course;

// Шаблонний рядок: вставка виразів ${...} і багаторядковість
const s2 = `Студентка ${name}, курс ${course}`;
const s3 = `Наступного року — ${course + 1} курс`;
const html = `
  <h2>${name}</h2>
  <p>Курс: ${course}</p>
`;
```

Рядки **незмінні** (immutable): методи не змінюють рядок, а повертають новий.

```js
const text = '  Привіт, Світ!  ';
text.length;              // 17
text.trim();              // 'Привіт, Світ!'
text.toUpperCase();       // '  ПРИВІТ, СВІТ!  '
text.includes('Світ');    // true
text.trim().startsWith('П'); // true
'abc'[0];                 // 'a' — доступ за індексом
'abc'.at(-1);             // 'c' — останній символ
'a-b-c'.split('-');       // ['a', 'b', 'c']
'ха'.repeat(3);           // 'хахаха'
'5'.padStart(3, '0');     // '005'
'JavaScript'.slice(0, 4); // 'Java'
```

### Логічний тип (boolean)

Два значення: `true` і `false`. Зазвичай є результатом порівнянь:

```js
const isAdult = age >= 18;
const hasDiscount = false;
```

### undefined і null

Обидва означають «немає значення», але з різним змістом:

- `undefined` — значення **ще не присвоєно**: змінна без ініціалізації, неіснуюча властивість об'єкта, функція без `return`.
- `null` — програміст **свідомо** вказав «тут порожньо».

```js
let selected;           // undefined — ще не вибрали
let user = null;        // null — користувача немає (явно)

typeof undefined;       // 'undefined'
typeof null;            // 'object' — помилка з першої версії мови, яку не виправили для сумісності
user === null;          // true — так правильно перевіряти null
```

### symbol і bigint

`symbol` — унікальний ідентифікатор, використовується для «прихованих» ключів об'єктів і у внутрішніх механізмах мови. `bigint` — цілі числа довільної довжини. У прикладних задачах курсу вони майже не трапляються, але знати про їхнє існування потрібно.

### Об'єкти (object)

Усе, що не примітив, — об'єкт: звичайні об'єкти `{}`, масиви `[]`, функції, дати, регулярні вирази. Об'єкти зберігають набір значень і передаються **за посиланням**. Детально — на лекції 6.

```js
const student = { name: 'Олена', course: 2 };
const marks = [90, 85, 77];

typeof student;          // 'object'
typeof marks;            // 'object' — масив теж об'єкт
Array.isArray(marks);    // true — правильна перевірка масиву
typeof function () {};   // 'function'
```

### Примітиви і посилання

| | Примітиви | Об'єкти |
|---|---|---|
| Зберігання | значення | посилання на об'єкт у пам'яті |
| Копіювання `b = a` | копія значення | копія посилання (той самий об'єкт) |
| Порівняння `===` | за значенням | за посиланням (чи це той самий об'єкт) |
| Змінність | незмінні | змінні |

```js
let a = 5;
let b = a;
b = 10;
console.log(a); // 5 — примітив скопійовано

const o1 = { x: 1 };
const o2 = o1;
o2.x = 99;
console.log(o1.x); // 99 — обидві змінні вказують на один об'єкт
```

## 5. Перетворення типів

Дані з форм, `prompt()`, URL чи файлів завжди приходять **рядками**. Тому перетворення типів — щоденна задача.

### Явне перетворення

```js
// До числа
Number('42');        // 42
Number('42px');      // NaN — увесь рядок має бути числом
Number('');          // 0  (!)
Number(' 12 ');      // 12 — пробіли по краях ігноруються
Number(true);        // 1
Number(null);        // 0
Number(undefined);   // NaN
parseInt('42px');    // 42 — читає, поки є цифри
parseFloat('3.5кг'); // 3.5
parseInt('08', 10);  // 8 — другий аргумент — система числення
+'15';               // 15 — унарний плюс, коротка форма Number()

// До рядка
String(42);          // '42'
(42).toString();     // '42'
String(null);        // 'null'
`${3.5}`;            // '3.5'

// До логічного
Boolean(1);          // true
Boolean('');         // false
!!'текст';           // true — подвійне заперечення
```

### Truthy і falsy

У логічному контексті (`if`, `&&`, `||`, `!`) будь-яке значення перетворюється на `true` або `false`. **Хибних (falsy) значень лише вісім**, запам'ятайте їх:

| Falsy-значення | Тип |
|---|---|
| `false` | boolean |
| `0`, `-0` | number |
| `0n` | bigint |
| `''` (порожній рядок) | string |
| `null` | null |
| `undefined` | undefined |
| `NaN` | number |

Усе інше — **правдиве (truthy)**, зокрема `'0'`, `'false'`, `' '`, `[]`, `{}`.

```js
if ('0') console.log('рядок "0" — truthy!');
if ([]) console.log('порожній масив — truthy!');
```

### Неявне перетворення (coercion)

Оператори самі перетворюють операнди, і правила не завжди інтуїтивні:

```js
'5' + 3;      // '53'  — якщо хоч один операнд рядок, + склеює
'5' - 3;      // 2     — мінус працює лише з числами, '5' → 5
'5' * '2';    // 10
'10' / '4';   // 2.5
true + 1;     // 2     — true → 1
[] + [];      // ''    — масиви → рядки
'3' + 4 + 5;  // '345' — зліва направо: '3'+4 = '34', потім '34'+5
3 + 4 + '5';  // '75'  — 3+4 = 7, потім 7+'5' = '75'
```

:::caution[Типова помилка з формами]
```js
const a = '10'; // значення з input — завжди рядок
const b = '5';
console.log(a + b);                 // '105' — склеїли!
console.log(Number(a) + Number(b)); // 15 — правильно
```
Перетворюйте дані з полів введення на числа **одразу** після читання і перевіряйте результат через `Number.isNaN()`.
:::

## 6. Оператори

### Арифметичні

| Оператор | Дія | Приклад | Результат |
|---|---|---|---|
| `+` | додавання / конкатенація | `7 + 2` | `9` |
| `-` | віднімання | `7 - 2` | `5` |
| `*` | множення | `7 * 2` | `14` |
| `/` | ділення | `7 / 2` | `3.5` |
| `%` | остача від ділення | `7 % 2` | `1` |
| `**` | степінь | `7 ** 2` | `49` |
| `++` / `--` | інкремент / декремент | `i++` | `i + 1` |

Остача `%` корисна для перевірки парності (`n % 2 === 0`), циклічних індексів, розкладу секунд на хвилини.

Різниця префіксного й постфіксного інкременту:

```js
let i = 5;
console.log(i++); // 5 — спочатку повертає старе значення, потім збільшує
console.log(i);   // 6
console.log(++i); // 7 — спочатку збільшує, потім повертає
```

У виразах інкремент плутає читача; використовуйте його окремою інструкцією (`i++;`) або в заголовку циклу.

### Присвоєння

```js
let total = 100;
total += 50;   // total = total + 50  → 150
total -= 20;   // 130
total *= 2;    // 260
total /= 4;    // 65
total %= 10;   // 5
total **= 2;   // 25

let name = '';
name ||= 'Гість';   // присвоїти, якщо name falsy
let limit = null;
limit ??= 1000;     // присвоїти, якщо limit — null або undefined
```

### Порівняння

| Оператор | Значення |
|---|---|
| `===` | строга рівність (без перетворення типів) |
| `!==` | строга нерівність |
| `==` | нестрога рівність (з перетворенням типів) |
| `!=` | нестрога нерівність |
| `>`, `<`, `>=`, `<=` | більше, менше, … |

```js
5 === 5;       // true
5 === '5';     // false — різні типи
5 == '5';      // true  — рядок перетворено на число
0 == '';       // true  (!)
0 == false;    // true  (!)
null == undefined;  // true
null === undefined; // false
```

:::danger[Завжди === і !==]
Нестрога рівність `==` має складну таблицю перетворень, яку ніхто не пам'ятає напам'ять. У курсі використовуємо **лише** `===` і `!==`. Єдиний поширений виняток у чужому коді — `x == null`, що перевіряє одночасно `null` і `undefined`.
:::

Рядки порівнюються **посимвольно за кодами Unicode** (лексикографічно):

```js
'b' > 'a';       // true
'Б' > 'А';       // true
'10' > '9';      // false! порівнюються символи '1' і '9'
10 > '9';        // true — рядок '9' перетворено на число
'apple' < 'Apple'; // false — великі літери мають менші коди
```

Для правильного порівняння рядків з урахуванням мови є `a.localeCompare(b, 'uk')`.

### Логічні оператори

| Оператор | Назва | Повертає |
|---|---|---|
| `&&` | І (AND) | перше falsy-значення або останнє, якщо всі truthy |
| `\|\|` | АБО (OR) | перше truthy-значення або останнє, якщо всі falsy |
| `!` | НЕ (NOT) | `true` / `false` (інвертоване логічне значення) |
| `??` | оператор нульового злиття (nullish coalescing) | лівий операнд, якщо він не `null`/`undefined`, інакше правий |

Важливо: `&&` і `||` повертають **не обов'язково `true`/`false`**, а одне з самих значень. І обчислюються за **короткою схемою** (short-circuit): якщо результат зрозумілий з лівого операнда, правий не обчислюється.

```js
true && 'так';        // 'так'
0 && 'так';           // 0
'' || 'за замовчуванням'; // 'за замовчуванням'
'Олена' || 'Гість';   // 'Олена'
!0;                   // true
```

Різниця між `||` і `??` — дуже практична:

```js
const userDiscount = 0; // користувач свідомо поставив 0 %

const d1 = userDiscount || 10; // 10 — 0 вважається falsy, втратили значення!
const d2 = userDiscount ?? 10; // 0 — ?? реагує лише на null/undefined
```

Правило: **для значень за замовчуванням використовуйте `??`**, якщо `0` або `''` — допустимі значення.

### Опціональний ланцюжок ?.

Оператор `?.` (optional chaining) безпечно звертається до властивості: якщо ліворуч `null` або `undefined`, результат — `undefined` замість помилки.

```js
const order = { customer: null };

order.customer.name;          // TypeError: Cannot read properties of null
order.customer?.name;         // undefined
order.customer?.name ?? 'Анонім'; // 'Анонім'
```

### Тернарний оператор

Єдиний оператор з трьома операндами: `умова ? значення1 : значення2`. Це **вираз**, тобто він повертає значення:

```js
const age = 17;
const status = age >= 18 ? 'повнолітній' : 'неповнолітній';
const cartLabel = `У кошику: ${count > 0 ? count + ' шт.' : 'порожньо'}`;
```

Не вкладайте тернарні оператори один в одного більше ніж на один рівень — для цього є `if...else` (наступна лекція).

### Оператор typeof і інші

```js
typeof 42;          // 'number'
typeof 'hi';        // 'string'
typeof undefined;   // 'undefined'
typeof undeclared;  // 'undefined' — не кидає помилку для неоголошених змінних

'name' in { name: 'A' };   // true — чи є властивість в об'єкті
[] instanceof Array;       // true — чи створено об'єкт цим конструктором
```

## 7. Пріоритет операторів і типові помилки

Оператори виконуються за **пріоритетом** (precedence), як у математиці. Спрощена таблиця (від вищого до нижчого):

| Пріоритет | Оператори |
|---|---|
| найвищий | `( )` групування, `.` `?.` `[]` доступ, виклик `()` |
| | `!` `typeof` `++` `--` унарні `+` `-` |
| | `**` |
| | `*` `/` `%` |
| | `+` `-` |
| | `<` `>` `<=` `>=` `in` `instanceof` |
| | `===` `!==` `==` `!=` |
| | `&&` |
| | `\|\|` `??` |
| | `? :` |
| найнижчий | `=` `+=` `-=` … |

```js
2 + 3 * 4;        // 14
(2 + 3) * 4;      // 20
!true || true;    // true — ! виконується першим
2 ** 3 ** 2;      // 512 — ** правоасоціативний: 2 ** 9
```

:::tip
Не намагайтеся запам'ятати всю таблицю. Якщо сумніваєтеся — **ставте дужки**. Код має читатися без довідника. Зауважте: змішувати `??` з `||` чи `&&` без дужок заборонено синтаксисом — `a || b ?? c` дасть `SyntaxError`.
:::

### Типові помилки початківців

| Помилка | Приклад | Як правильно |
|---|---|---|
| Склеювання замість додавання | `input.value + 5` | `Number(input.value) + 5` |
| `=` замість `===` в умові | `if (x = 5)` | `if (x === 5)` |
| Перевірка NaN через `===` | `x === NaN` | `Number.isNaN(x)` |
| Порівняння дробових чисел | `0.1 + 0.2 === 0.3` | `Math.abs(a - b) < Number.EPSILON` або округлення |
| `\|\|` для значень за замовчуванням | `count \|\| 1` при `count = 0` | `count ?? 1` |
| Звернення до змінної до `let` | TDZ → ReferenceError | оголошувати вгорі блоку |
| Зміна `const` | `const x = 1; x++` | `let`, якщо значення змінюється |
| `typeof null === 'null'` | очікування не справджується | `value === null` |

## Підсумки

- JavaScript відповідає за поведінку сторінки; виконується рушієм браузера і має доступ до Web API. Скрипт підключаємо у `<head>` з атрибутом `defer`.
- Змінні оголошуємо через `const` (за замовчуванням) або `let` (якщо значення змінюється). `var` — застарілий, має функціональну область видимості й небезпечне підняття.
- У JS 7 примітивних типів (`number`, `bigint`, `string`, `boolean`, `undefined`, `null`, `symbol`) і об'єкти. Примітиви копіюються за значенням, об'єкти — за посиланням.
- Дані з форм — рядки; їх треба явно перетворювати (`Number()`, `parseFloat()`). Пам'ятайте вісім falsy-значень.
- Порівнюємо лише через `===`/`!==`. Для значень за замовчуванням — `??`, для безпечного доступу — `?.`.
- У сумнівних місцях пріоритету — дужки.
