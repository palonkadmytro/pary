## Мета роботи

- Навчитися проєктувати й писати функції з типізованими параметрами, значеннями за замовчуванням і типом повернення.
- Застосувати стрілкові функції та функції вищого порядку (`array_filter`, `array_map`, `array_reduce`, `usort`) до реальних даних.
- Написати функцію, що повертає іншу функцію (замикання, `Closure`).
- Організувати код у кілька файлів (`require __DIR__ . ...`), використати файл, що повертає дані (`return [...]`).
- Написати прості автоматичні перевірки (тести) своїх функцій.
- Підготувати файл `helpers.php`, який на наступній парі перенесемо в наскрізний проєкт «Міні-блог».

## Що потрібно

- XAMPP (Apache) або `php -S`, VS Code + PHP Intelephense.
- Папка `practice-04` з попередньої роботи (візьмемо з неї `style.css`).
- Матеріал лекції 3 «Функції у PHP».

## Короткі теоретичні відомості

Добра функція:

| Принцип | Що означає | Приклад |
|---|---|---|
| Одна відповідальність | робить одну річ і її назва це описує | `format_date()` лише форматує дату, а не виводить її |
| Явні входи і виходи | усе потрібне — через параметри, результат — через `return` | не використовує `global` |
| Типи | параметри і результат типізовані | `function excerpt(string $text, int $length = 150): string` |
| Передбачуваність | однакові аргументи → однаковий результат, без побічних ефектів | не змінює масиви, передані їй |
| Обробка граничних випадків | порожній рядок, порожній масив, неіснуючий id | `find_post()` повертає `null`, якщо поста немає |

Структура папки після роботи:

```text
practice-05/
├── helpers.php    # універсальні хелпери: e(), excerpt(), format_date(), plural()...
├── posts.php      # функції для роботи з масивом постів
├── data.php       # тестові дані: повертає масив постів
├── tests.php      # сторінка з автоматичними перевірками
├── index.php      # сторінка-прототип списку постів
└── style.css
```

Файли `helpers.php`, `posts.php` і `data.php` **нічого не виводять** — вони лише оголошують функції або повертають дані. Виводять HTML тільки `index.php` і `tests.php`. Такий поділ дозволяє підключати функції будь-де без побічних ефектів.

### Крок 2. Перша функція: `e()` — безпечне виведення

Створіть `helpers.php` і почніть з найважливішої функції проєкту:

```php title="helpers.php"
<?php
declare(strict_types=1);

/**
 * Екранує рядок для безпечного виведення в HTML.
 * Використовуйте для КОЖНОГО значення, яке потрапляє в розмітку.
 */
function e(?string $value): string
{
    return htmlspecialchars($value ?? '', ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}
```

Розберемо `htmlspecialchars()`:

| Символ | Перетворюється на | Навіщо |
|---|---|---|
| `&` | `&amp;` | щоб `&copy;` у тексті не став символом © |
| `<` і `>` | `&lt;` і `&gt;` | щоб текст не став HTML-тегом |
| `"` | `&quot;` | щоб значення не «вирвалося» з атрибута `value="..."` |
| `'` | `&#039;` | те саме для атрибутів в одинарних лапках (вмикає прапорець `ENT_QUOTES`) |

- `ENT_SUBSTITUTE` — замінює некоректні UTF-8 послідовності символом `�` замість того, щоб повернути порожній рядок.
- `'UTF-8'` — кодування явно.
- Тип параметра `?string` і `$value ?? ''` дозволяють безпечно передати `null` (наприклад, поле, якого немає в даних).

Чому це важливо? Уявіть, що заголовок поста ввів користувач:

```php
$title = '<script>alert("Зламано!")</script>';

echo "<h2>$title</h2>";        // браузер ВИКОНАЄ скрипт
echo '<h2>' . e($title) . '</h2>'; // браузер ПОКАЖЕ текст: <script>alert("Зламано!")</script>
```

Друге виведення дає в HTML `&lt;script&gt;alert(&quot;Зламано!&quot;)&lt;/script&gt;` — браузер відображає це як звичайний текст. Створіть тимчасовий файл `xss-demo.php` з цим кодом (підключивши `helpers.php`) і переконайтеся в різниці самі. Детально атаку XSS розберемо на П7.

:::tip[Чому така коротка назва]
Функція викликатиметься в шаблонах десятки разів: `<?= e($post['title']) ?>`. Коротка назва `e` (від *escape*) — поширена домовленість (так само називається хелпер у Laravel). Головне правило: **кожне значення, що потрапляє в HTML, проходить через `e()`**.
:::

### Крок 3. Хелпери для тексту і дат

Допишіть у `helpers.php` решту функцій:

```php title="helpers.php (продовження)"
/**
 * Короткий уривок тексту: не довший за $length символів, без розрізання слів.
 */
function excerpt(string $text, int $length = 150): string
{
    $text = trim($text);
    if (mb_strlen($text) <= $length) {
        return $text;
    }

    // Беремо на 1 символ більше, щоб дізнатися, чи межа не припала на кінець слова
    $cut = mb_substr($text, 0, $length + 1);
    $lastSpace = mb_strrpos($cut, ' ');

    $cut = $lastSpace !== false
        ? mb_substr($cut, 0, $lastSpace)      // обрізаємо по останньому пробілу
        : mb_substr($text, 0, $length);       // одне дуже довге слово — ріжемо як є

    return rtrim($cut, ' .,;:!?') . '…';
}

/**
 * Дата українською: '2026-02-13 10:20:00' → '13 лютого 2026, 10:20'.
 */
function format_date(string $datetime): string
{
    $timestamp = strtotime($datetime);
    if ($timestamp === false) {
        return $datetime;                     // не вдалося розібрати — повертаємо як є
    }

    $months = [
        1 => 'січня', 'лютого', 'березня', 'квітня', 'травня', 'червня',
        'липня', 'серпня', 'вересня', 'жовтня', 'листопада', 'грудня',
    ];
    $month = $months[(int) date('n', $timestamp)];

    return date('j', $timestamp) . " {$month} " . date('Y, H:i', $timestamp);
}

/**
 * Число зі словом у правильній формі: 1 пост, 3 пости, 5 постів.
 */
function plural(int $n, string $one, string $few, string $many): string
{
    $mod10 = abs($n) % 10;
    $mod100 = abs($n) % 100;

    $form = match (true) {
        $mod10 === 1 && $mod100 !== 11                         => $one,
        $mod10 >= 2 && $mod10 <= 4 && ($mod100 < 12 || $mod100 > 14) => $few,
        default                                                => $many,
    };

    return "{$n} {$form}";
}

/**
 * Кількість слів у тексті.
 */
function word_count(string $text): int
{
    $words = preg_split('/\s+/u', trim($text), -1, PREG_SPLIT_NO_EMPTY);
    return count($words);
}

/**
 * Орієнтовний час читання в хвилинах (200 слів за хвилину, мінімум 1).
 */
function reading_time(string $text, int $wordsPerMinute = 200): int
{
    return max(1, (int) ceil(word_count($text) / $wordsPerMinute));
}
```

Що тут варто помітити:

- **`excerpt()`** використовує тільки `mb_*`-функції, бо працює з кирилицею. Трюк з `$length + 1`: якщо символ одразу після межі — пробіл, то межа припала на кінець слова і слово зберігається повністю. `rtrim($cut, ' .,;:!?')` прибирає розділові знаки перед «…» (усі ці символи однобайтові, тому байтова `rtrim` тут безпечна).
- **`format_date()`** обробляє граничний випадок: `strtotime()` повертає `false`, якщо не зміг розібрати рядок. Без перевірки під `strict_types` виклик `date('j', false)` дав би `TypeError`. Масив місяців починається з ключа `1` — решта ключів (2, 3, …) призначаються автоматично.
- **`plural()`** реалізує правила української мови: 1, 21, 101 — «пост»; 2–4, 22–24 — «пости»; 5–20, 11–14, 25–30 — «постів». `match (true)` перевіряє умови по черзі.
- **`word_count()`** розбиває текст регулярним виразом `\s+` (будь-яка кількість пробільних символів) з модифікатором `u` (UTF-8). Прапорець `PREG_SPLIT_NO_EMPTY` відкидає порожні елементи — інакше для порожнього рядка ми отримали б 1 «слово».
- **`reading_time()`** викликає іншу нашу функцію — так будуються програми: маленькі функції складаються у більші. `(int) ceil(...)` — бо `ceil()` повертає `float`.

`require` може повертати значення: якщо підключений файл містить `return`, результат можна присвоїти змінній — `$posts = require __DIR__ . '/data.php';`. Цей прийом часто використовують для файлів конфігурації (наприклад, `config.php`, що повертає масив налаштувань).

Важлива властивість цього формату: **рядки порівнюються в тому самому порядку, що й дати**, бо розряди йдуть від старшого (рік) до молодшого (секунди). Тому для сортування не потрібно перетворювати дати на числа.

### Крок 5. Функції для роботи з постами

Створіть `posts.php`:

```php title="posts.php"
<?php
declare(strict_types=1);

/**
 * Пости, у заголовку або тексті яких є $query (без урахування регістру).
 */
function filter_posts(array $posts, string $query): array
{
    $query = trim($query);
    if ($query === '') {
        return $posts;                        // порожній запит — повертаємо все
    }

    $found = array_filter(
        $posts,
        fn(array $post): bool => mb_stripos($post['title'], $query) !== false
            || mb_stripos($post['body'], $query) !== false
    );

    return array_values($found);              // перенумеровуємо ключі 0, 1, 2...
}

/**
 * Сортування постів: 'new' — нові першими, 'old' — старі першими, 'title' — за назвою.
 */
function sort_posts(array $posts, string $sort = 'new'): array
{
    $compare = match ($sort) {
        'old'   => fn(array $a, array $b): int => [$a['created_at'], $a['id']] <=> [$b['created_at'], $b['id']],
        'title' => fn(array $a, array $b): int => mb_strtolower($a['title']) <=> mb_strtolower($b['title']),
        default => fn(array $a, array $b): int => [$b['created_at'], $b['id']] <=> [$a['created_at'], $a['id']],
    };

    usort($posts, $compare);                  // сортуємо КОПІЮ — масив передано за значенням
    return $posts;
}

/**
 * Пост за id або null, якщо такого немає.
 */
function find_post(array $posts, int $id): ?array
{
    foreach ($posts as $post) {
        if ($post['id'] === $id) {
            return $post;
        }
    }
    return null;
}

/**
 * Повертає ФУНКЦІЮ-фільтр, яка перевіряє автора поста.
 */
function by_author(string $author): Closure
{
    return fn(array $post): bool => $post['author'] === $author;
}

/**
 * Унікальні автори в алфавітному порядку.
 */
function authors(array $posts): array
{
    $authors = array_unique(array_column($posts, 'author'));
    sort($authors);                           // sort() змінює масив на місці і перенумеровує ключі
    return $authors;
}

/**
 * Загальна кількість слів у всіх постах.
 */
function total_words(array $posts): int
{
    return array_reduce(
        $posts,
        fn(int $carry, array $post): int => $carry + word_count($post['body']),
        0
    );
}
```

Розбір ключових рішень:

1. **`filter_posts()`** — `array_filter` зі стрілковою функцією, яка «бачить» `$query` автоматично (захоплення за значенням). `mb_stripos` шукає без урахування регістру і повертає позицію або `false`; порівнюємо строго `!== false`, бо збіг на початку рядка дає позицію `0`. `array_values` — щоб після фільтрації ключі знову йшли 0, 1, 2.
2. **`sort_posts()`** — `match` повертає **функцію порівняння**, яку потім передаємо в `usort`. Порівняння масивів `[$b['created_at'], $b['id']] <=> [...]` сортує за датою, а при однаковій даті — за `id`. Масив `$posts` передано за значенням, тому `usort` сортує локальну копію, а оригінал у викликаючому коді не змінюється.
3. **`find_post()`** — тип повернення `?array`: або масив поста, або `null`. Ранній `return` з циклу.
4. **`by_author()`** — функція, що **повертає функцію** (тип `Closure`). `by_author('Олена')` створює фільтр, який «пам'ятає» ім'я автора. Використання: `array_filter($posts, by_author('Олена'))`.
5. **`total_words()`** — `array_reduce` згортає масив постів до одного числа; початкове значення акумулятора `0`.

:::note
Сортування `'title'` порівнює рядки побайтово. Латинські літери в UTF-8 мають менші коди, ніж кирилиця, тому «match замість switch» опиниться першим. Крім того, літери «є», «і», «ї», «ґ» мають коди більші за «я» і сортуються неправильно. Для коректного алфавітного порядку існує клас `Collator` з розширення `intl` — це завдання ★★★.
:::

### Крок 6. Автоматичні перевірки

Перевіряти функції «на око» в браузері довго і ненадійно. Напишемо мінімальний «фреймворк» для тестів — функцію `check()`, яка порівнює фактичний результат з очікуваним.

```php title="tests.php"
<?php
declare(strict_types=1);

require __DIR__ . '/helpers.php';
require __DIR__ . '/posts.php';

$results = [];   // сюди check() складатиме результати перевірок

/**
 * Порівнює фактичний результат з очікуваним і запам'ятовує підсумок.
 */
function check(array &$results, string $label, mixed $actual, mixed $expected): void
{
    $results[] = [
        'label'    => $label,
        'passed'   => $actual === $expected,
        'actual'   => var_export($actual, true),
        'expected' => var_export($expected, true),
    ];
}

// e()
check($results, 'e: теги і лапки', e('<b>"Том & Джеррі"</b>'), '&lt;b&gt;&quot;Том &amp; Джеррі&quot;&lt;/b&gt;');
check($results, 'e: апостроф', e("O'Reilly"), 'O&#039;Reilly');
check($results, 'e: null', e(null), '');

// excerpt()
check($results, 'excerpt: короткий текст без змін', excerpt('Привіт, світе', 20), 'Привіт, світе');
check($results, 'excerpt: межа на кінці слова', excerpt('Один два три чотири', 12), 'Один два три…');
check($results, 'excerpt: межа посеред слова', excerpt('Один два три чотири', 10), 'Один два…');
check($results, 'excerpt: одне довге слово', excerpt('Суперкаліфраджилістик', 5), 'Супер…');

// format_date()
check($results, 'format_date', format_date('2026-02-13 10:20:00'), '13 лютого 2026, 10:20');
check($results, 'format_date: 1 січня', format_date('2026-01-01 08:05:00'), '1 січня 2026, 08:05');

// plural()
```

Зверніть увагу:

- `check()` приймає `array &$results` **за посиланням** — тому кожен виклик додає рядок у той самий масив `$results`. Це один з небагатьох випадків, коли посилання доречне (інша альтернатива — повертати рядок і писати `$results[] = check(...)`).

### Крок 8. Експерименти з типами й аргументами

Створіть тимчасовий файл `experiments.php`, підключіть `helpers.php` і по черзі спробуйте:

```php title="experiments.php"
<?php
declare(strict_types=1);

require __DIR__ . '/helpers.php';

$text = 'Один два три чотири';

// 1. Іменовані аргументи — у будь-якому порядку
echo excerpt(length: 10, text: $text), '<br>';      // Один два…

// 2. Неправильний тип аргументу під strict_types
echo excerpt($text, '10');
// TypeError: excerpt(): Argument #2 ($length) must be of type int, string given

// 3. Пропущений обов'язковий аргумент
// echo excerpt();
// ArgumentCountError: Too few arguments to function excerpt(), 0 passed ... and at least 1 expected

// 4. float замість int
// echo plural(2.5, 'бал', 'бали', 'балів');
// TypeError: plural(): Argument #1 ($n) must be of type int, float given
```

Кожну помилку прочитайте повністю: PHP вказує **назву функції, номер і назву параметра, очікуваний і фактичний тип та рядок виклику**. Потім закоментуйте рядок і переходьте до наступного.

А тепер приберіть `declare(strict_types=1);` і повторіть пункт 2: помилки не буде, рядок `'10'` мовчки перетвориться на число. Поверніть директиву — у проєкті ми завжди працюємо в строгому режимі.

:::caution[Дані з форм]
Наступної пари ми отримуватимемо дані з `$_GET` і `$_POST` — а там **усе рядки**. Виклик `excerpt($body, $_GET['length'])` під `strict_types` впаде з `TypeError`. Тому значення з запиту треба спочатку перевірити і перетворити (`filter_var`, `(int)`), а вже потім передавати в типізовані функції.
:::
